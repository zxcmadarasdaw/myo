# Матрица совместимости

Состояние на 2026-11-17. Fedora-имена взяты из текущих провайдеров и установочных модулей. Для Arch прочитаны каталоги Core и Extra x86_64, для CachyOS — зеркало Extra x86_64 и страницы основных пакетов. Версии и репозиторий на конкретной машине нужно сверять через `pacman -Si` с её конфигурацией зеркал и вариантами x86-64-v3/v4. Каталоги показывают наличие пакета, фактическая установка и ABI проверяются в Linux. [Arch Core](https://geo.mirror.pkgbuild.com/core/os/x86_64/) · [Arch Extra](https://geo.mirror.pkgbuild.com/extra/os/x86_64/) · [CachyOS Extra](https://archlinux.cachyos.org/repo/extra/os/x86_64/) · [Оптимизированные репозитории CachyOS](https://wiki.cachyos.org/features/optimized_repos/)

## Покрытие списка зависимостей

- Все 35 имён из `REQUIRED_PKGS` найдены в Arch Core/Extra. Все из списка, кроме Core-пакетов `file` и `python`, также найдены в проверенной базе CachyOS Extra. Проверить эти два имени из фактической базы Core на целевой системе. Основной список на проверенном снимке не требует AUR.
- Такие же имена с обеих сторон в карте — `kitty zbar tesseract wl-clipboard cliphist jq ddcutil bluez matugen pipewire wireplumber pipewire-alsa file fastfetch quickshell grim playerctl satty xdg-desktop-portal-gtk qt6ct adwaita-icon-theme gpu-screen-recorder wf-recorder`. Отличающиеся имена и пакеты выше, в том числе Fedora `adw-gtk3-theme` соответствует Arch `adw-gtk-theme`.
- Дополнительные пути установки проверять отдельно. `base-devel` является пакетом, а не командой, поэтому текущая bootstrap-проверка `command -v base-devel` его не обнаружит. Развести bootstrap CLI и инструменты сборки. Проверить исполнение `flock/setsid`, `notify-send`, `xdg-open`, `ping`, `busctl` и OpenSSL/CA.
- Рецепты stable/git содержат `qt6-multimedia` и `quickshell` без явной зависимости `qt6-imageformats` и без минимальной версии Quickshell. Сверить рецепты с живыми требованиями, поставкой VPN и форматом systemd units перед тем, как заявлять эквивалентность двух вариантов установки.

## Дополнения к рабочему install.sh

- Arch: `qt6-multimedia-ffmpeg` при отсутствии выбранного GStreamer, а также `polkit python-yaml iproute2 nftables`. Отдельный AUR-helper не требуется. Команда оболочки — `quickshell`.
- Fedora: `pulseaudio-utils` для `pactl`, остальная карта DNF сохранена. Из Fedora RPM-комплекта по прежнему ставятся только недостающие зависимости VPN.
- Исполняемые файлы Serpantinum находятся в пользовательском каталоге установки. Systemd unit, polkit actions и VPN helpers — в системных путях, указанных в [архитектуре](ARCHITECTURE.md). Arch нативный пакет и shell-установка имеют раздельное владение файлами.
