# Проверка установщика

## Локальные проверки

- `bash install/tests/install_runtime_test.sh` проверяет определение Fedora, CachyOS и Arch, адаптеры пакетов с заглушками, развёртывание и сохранение пользовательских настроек.
- `bash install/tests/installer_manager_test.sh` проверяет инвентарь, подготовку, ограничения Live и действия pacman/DNF с заглушками.
- `python3 install/tests/installer_manager_test.py` проверяет утверждение плана, HTTP-сессию графического мастера, статусы и журнал. Сценарии PTY выполняются на Linux.

## Приёмка на Linux

Используйте чистые снимки Fedora 45, CachyOS и CachyOS Live с обычным пользователем. Графическая сессия должна иметь браузер по умолчанию. Перед проверкой каждого сценария возвращайте чистый снимок либо фиксируйте состояние пакетов, служб, конфигураций и свободного места.

| Сценарий | Действия и ожидаемый результат |
| --- | --- |
| Графический запуск | Запустить `bash install.sh` до установки Quickshell. Проверить ОС, версию, пакеты, раскрытие компонентов и оценку свободного места. |
| Терминал | Запустить `bash install.sh --tui` из TTY. Проверить те же настройки, обзор плана, журнал и отмену. |
| Сухая подготовка | Сравнить файлы настроек и список пакетов до и после `--check` и после выхода с экрана плана. |
| Fedora | Установить Hyprland и оболочку через DNF, проверить подтверждения транзакции и запроса ключа COPR, отсутствие Terra в транзакции Hyprland и отдельный запуск с VPN. |
| CachyOS и Arch | Установить через pacman из согласованных баз. Проверить диалоги провайдера и подтверждения транзакции, запуск оболочки и сохранение другого дисплейного менеджера. |
| Live | Проверить ограниченную overlay FS. При недостатке места убедиться, что мастер блокирует план. В Live отсутствует автообновление всей системы. |
| AUR | Проверить отсутствие официального Quickshell в отдельном тестовом снимке. Разрешить AUR и сборку, сверить показанный рецепт, отложить ответ и подтвердить только проверенный рецепт. Убедиться, что makepkg запущен пользователем. |
| Сеть и блокировка | Отключить сеть в VM во время загрузки и проверить сообщение и повтор. Занять pacman второй безопасной операцией в VM, увидеть путь к lock и проверить его сохранение. |
| Скрытый запрос | Дождаться нестандартного вопроса, открыть ручной ввод, ответить через журнал. Проверить маскировку sudo и отсутствие пароля в журнале. |
| Отмена | Отменить загрузку, сборку и запись конфигурации отдельно. Дождаться завершения дочерних процессов перед повтором. Проверить доступность исходных файлов или их резервных копий. |
| Обслуживание | Запустить Verify, Repair, Update, Install Missing. Создать локальное изменение в Hyprland и в настройках Serpantinum, подтвердить их сохранение при обновлении. |

Открыты полное развёртывание оболочки в чистых графических сессиях Fedora и CachyOS, реальная AUR-сборка, запуск TUN и установка всей группы зависимостей на Live.
