# Проверка установщика

## Системные обновления

- В CachyOS Live на VirtualBox графический установщик автоматически нашёл 599 обновлений в четырёх репозиториях. Сервер отклонил попытку запустить полное обновление в Live.
- В отдельном корне pacman зеркало с HTTP 404 было пропущено при проверке репозитория и при загрузке пакета. После отказа в нативном запросе версия пакета сохранилась. Повтор взял архив из кэша, проверил подпись и обновил `iana-etc` с `20260530-1` до `20260617-1` после подтверждения.
- В Fedora 45 внутри отдельного rootfs проверили план DNF5, оценку размера, подтверждение, обновление `expat` с `2.8.3-1.fc45` до `2.9.0-1.fc45` и повторную проверку с пустым списком обновлений.
- Chrome на ширине 390 px проверил английский и русский интерфейсы, историю, список в диалоге подтверждения, выбор Snapper и две строки прогресса загрузки на тестовых данных.
- На Linux прошли 8 тестов системных обновлений, 8 тестов менеджера, 34 теста очереди, 5 групп проверок подготовки и 30 проверок среды установки.

Открыта приёмка полного обновления рабочего CachyOS на SSD, создания снимка Snapper на настроенной системе и нативных сценариев Void, AUR, Flatpak и перезагрузки.

## Очередь загрузок — 18 ноября 2026

### Нативные проверки

- CachyOS Live 2026.08.09, pacman 7.1.0 / libalpm 16.0.1. Для подписанного `iana-etc` старый конфиг и кэш без `.sig` воспроизвели `error invoking external downloader` при `Total Download Size: 0.00 MiB`. Исправленный путь проверил этот же архив из кэша без сетевой загрузки пакета.
- В изолированный корень того же гостя установлены 248 пакетов. 247 архивов переиспользованы, скачан только `zfs-utils 2.4.4-3`. `pacman -Q` подтвердил Hyprland 0.57.2-1, Quickshell 0.3.2-1 и `zfs-utils`. Найдены `hyprland.desktop` и `hyprland-uwsm.desktop`. Hyprland с чистым окружением вернул `config ok` для Lua-конфигурации проекта. В минимальном chroot были сообщения ошибок отдельных скриптов и хуков, хотя pacman вернул 0 и зарегистрировал пакеты. Новых временных каталогов libalpm после транзакции не осталось.
- Fedora 45 в изолированном rootfs той же VM. DNF5 и Python API построили транзакцию для `tree 2.3.1-2.fc45`. Подписанный RPM прошёл проверку и был нативно установлен с `--cacheonly`. DNF5 указал ноль байт повторной загрузки.
- Две реальные сессии Plasma Wayland на CachyOS Live. После входа под вторым тестовым пользователем попытка выбрать чужую сессию была отклонена. Возврат из TTY активировал исходную сессию, второй рабочий стол остался зарегистрированным.

### Регрессии и пределы проверки

- 32 теста `python3 install/tests/download_queue_test.py` прошли и охватывают 651 позицию, режимы 1/4/8, адаптивное увеличение и снижение, настоящий локальный HTTP timeout, повреждённые и частичные архивы, смену зеркала, место, права, подписи, отсутствующую зависимость, повторное использование кэша и отчёт после неудачной нативной транзакции.
- 6 тестов `python3 install/tests/installer_manager_test.py` прошли на Linux, включая восстановление плана, смену boot ID, подтверждение, HTTP-протокол и PTY. В Bash прошли 5 групп тестов мастера и 28 тестов среды установки. Firefox показал две одновременные полосы прогресса и суммарную скорость на визуальной fixture.
- Осталась приёмка полного развёртывания Serpantinum с запуском Hyprland на физическом CachyOS Live USB и повторением исходного зависания именно между Hyprland-сессиями. Полное обновление хоста и нативный DNF4 в этом прогоне не выполнялись. 651 позиция проверена тестовым набором. Нативная транзакция содержала 248 реальных пакетов.

## Локальные проверки

- `bash install/tests/install_runtime_test.sh` проверяет определение Fedora, CachyOS и Arch, адаптеры пакетов с заглушками, развёртывание и сохранение пользовательских настроек.
- `bash install/tests/installer_manager_test.sh` проверяет инвентарь, подготовку, ограничения Live и действия pacman/DNF с заглушками.

## Приёмка на Linux

Используйте чистые снимки Fedora 45, CachyOS и CachyOS Live с обычным пользователем. Графическая сессия должна иметь браузер по умолчанию. Перед проверкой каждого сценария возвращайте чистый снимок либо фиксируйте состояние пакетов, служб, конфигураций и свободного места.

| Сценарий | Действия и ожидаемый результат |
| --- | --- |
| Графический запуск | Запустить `bash install.sh` до установки Quickshell. Проверить ОС, версию, пакеты, раскрытие компонентов и оценку свободного места. |
| Терминал | Запустить `bash install.sh --tui` из TTY. Проверить те же настройки, обзор плана, журнал и отмену. |
| Сухая подготовка | Сравнить файлы настроек и список пакетов до и после `--check` и после выхода с экрана плана. |
| Fedora | Установить Hyprland и оболочку через DNF, проверить подтверждения транзакции и запроса ключа COPR, отсутствие Terra в транзакции Hyprland и отдельный запуск с VPN. |
| CachyOS и Arch | Установить через pacman из согласованных баз. Проверить диалоги провайдера и подтверждения транзакции, запуск оболочки и сохранение другого дисплейного менеджера. |
| Live | Проверить ограниченную overlay FS. При недостатке места убедиться, что мастер блокирует план. В Live отсутствует автообновление всей системы. |
| AUR | Проверить отсутствие официального Quickshell в отдельном тестовом снимке. Разрешить AUR и сборку, сверить показанный рецепт, отложить ответ и подтвердить только проверенный рецепт. Убедиться, что makepkg запущен пользователем. |
| Сеть и блокировка | Отключить сеть в VM во время загрузки и проверить сообщение и повтор. Занять pacman второй безопасной операцией в VM, увидеть путь к lock и проверить его сохранение. |
| Скрытый запрос | Дождаться нестандартного вопроса, открыть ручной ввод, ответить через журнал. Проверить маскировку sudo и отсутствие пароля в журнале. |
| Отмена | Отменить загрузку, сборку и запись конфигурации отдельно. Дождаться завершения дочерних процессов перед повтором. Проверить доступность исходных файлов или их резервных копий. |
| Обслуживание | Запустить Verify, Repair, Update, Install Missing. Создать локальное изменение в Hyprland и в настройках Serpantinum, подтвердить их сохранение при обновлении. |

Открыты полное развёртывание оболочки в чистых графических сессиях Fedora и CachyOS, реальная AUR-сборка, запуск TUN и установка всей группы зависимостей на Live.
