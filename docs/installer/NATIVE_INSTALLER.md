# Проверка установщика Serpantinum

Проверено 23 ноября 2026 года. Источник сравнения — предоставленный `serpantinum-master (1).zip`, SHA-256 `5c54673dba8a8dfa222d5a5b95655a8d105cb8ee40242259509b0767f76024af`. В архиве лежит AGPL-3.0. Исправления сделаны в существующей реализации в этом репозитории.

## Как устанавливает оригинал

| Область | Поведение скриптов из ZIP |
| --- | --- |
| Вход и права | `install/get.sh` получает `install/install.sh` и передаёт ему терминал. Основной скрипт подготавливает checkout, запускает терминальный мастер от текущего пользователя и вызывает `sudo` для системных изменений. |
| Выбор дистрибутива | `install/modules/pm.sh` читает `ID` и `ID_LIKE` из `/etc/os-release`, затем проверяет доступность DNF, pacman или XBPS. |
| Fedora | `pm/dnf.sh` переводит логические имена в имена RPM, вызывает `dnf install` для группы, затем обрабатывает отдельные COPR и релизные источники. Hyprland и Quickshell идут через Fedora или настроенные COPR. Оригинал подтверждает транзакции через `-y` и при первом подключении Terra использует `--nogpgcheck` для `terra-release`. |
| Arch и CachyOS | `pm/pacman.sh` использует пакетные операции pacman и опциональные сборки AUR. В оригинале подготовка может вызвать `-Sy`, первичная установка выполняет `-Syyu`, отдельные пакеты идут через `-S`. Эти варианты зависят от актуальности зеркал и размера системного раздела. |
| Развёртывание и контроль | `deps.sh` ведёт список неудачных пакетов и проверяет версию Quickshell. `deploy.sh` копирует конфиги и программу, создаёт команды запуска и настраивает SDDM по выбору пользователя. Основной скрипт записывает версию и выводит экран завершения. |

## Что изменилось

- Обычный запуск использует окно Qt и существующий Bash-бэкенд через псевдотерминал. **Подготовить систему** выводит план и ограничения. Штатные вопросы DNF, pacman и sudo приходят в окно и в TUI. Ответ на запрос о пароле скрыт. Для отдельного менеджера обновлений `--system-updates` действует прежний loopback-интерфейс. Его HTTP-маршруты обслуживают обновления и закрытие окна.
- Этап 2 запускает пакетный менеджер с тремя потоками на PTY. Раньше обвязка оставляла `stderr` в pipe, хотя часть нативных сценариев определяет режим работы по наличию терминала. Регрессия с пакетом на этапе 2 воспроизводит отсутствие запроса на старой версии. Новый путь показывает запрос, принимает ответ и фиксирует код команды.
- CachyOS Live 2026.08.09 выставлял `DisableDownloadTimeout`. В тесте pacman оставался на HTTPS-соединении после синхронизации баз. Временная конфигурация Serpantinum восстанавливает штатный тайм-аут, использует встроенный загрузчик, сохраняет зеркала, кэш и политику подписей. Рабочий путь проверяет блокировку pacman и отклоняет план с несогласованными базами. Полное обновление доступно по отдельному выбору на установленной системе.
- Fedora передаёт загрузку, кэш и проверку подписей DNF/RPM. В Fedora 45 исходный COPR Hyprland пустой. Выбран `sdegler/hyprland` для современного Hyprland и сохранён `errornointernet/quickshell` для Quickshell от 0.3. Сборки Kitty из COPR-композитора исключены для транзакции установщика, чтобы DNF мог взять Kitty из Fedora. [Каталог исходного COPR](https://download.copr.fedorainfracloud.org/results/mineiro/hyprland/fedora-45-x86_64/) · [Hyprland в COPR](https://download.copr.fedorainfracloud.org/results/sdegler/hyprland/fedora-45-x86_64/) · [Quickshell в COPR](https://download.copr.fedorainfracloud.org/results/errornointernet/quickshell/fedora-45-x86_64/)
- План показывает свободное место, файловую систему корня, доступную память и расположение кэша. Для Live с отсутствующими пакетами требуется 1 ГиБ свободного места под системными каталогами. Pacman дополнительно оценивает размер загрузки и установленного набора. Если кэш находится на той же файловой системе, учитывается сумма этих оценок. DNF печатает собственную разбивку размера до подтверждения транзакции.
- Завершение установки зависит от проверки пакетов, минимальных версий, конфигов, QML, команды запуска и записи Wayland-сессии. В режиме проверки ошибка возвращает ненулевой код. Запуск оболочки доступен отдельным действием после успешной проверки.

## Что подтвердилось

| Проверка | Результат |
| --- | --- |
| CachyOS Live VM, отдельный корень pacman | Нативная транзакция установила Hyprland 0.57.2-1 и Quickshell 0.3.2-1. Установлены остальные зависимости и найдены `hyprland.desktop` и `hyprland-uwsm.desktop`. Повтор с `--needed` завершился без переустановки. После развёртывания с текущего checkout команда Verify подтвердила конфиги, QML, запускной файл и запись сессии. Repair восстановил убранную перед тестом ссылку `serpantinumd`. |
| Fedora 45, изолированный rootfs, DNF5 | Установлены Hyprland 0.57.2, Quickshell 0.3.2 и Kitty 0.48.2 из Fedora. Ключи COPR сверены с опубликованными ключами проектов, подтверждения переданы вручную. Повтор вернул `Nothing to do`. Для плана повторной установки Kitty из нативного кэша DNF показал `Need to download 0 B`. После установки зависимостей завершены развёртывание с текущего checkout и отдельная команда Verify. |
| RPM из сообщения об ошибке | Fedora RPM `kitty-0.48.2-1.fc45.x86_64.rpm` прошёл `rpmkeys --checksig` с Fedora-ключом. Та же копия с пустой базой ключей дала `digests SIGNATURES NOT OK`. После изменения байтов отдельная копия дала `DIGESTS SIGNATURES NOT OK` даже с правильным ключом. Историческая очередь проверяла RPM до этапа DNF и требовала строку `signatures OK`. Воспроизведён механизм ошибки при отсутствующем ключе. Состояние ключей на машине из исходного сообщения неизвестно. |
| Нативный интерфейс | Окно открыто в Plasma Wayland гостя, русский и английский режимы, расширенная вкладка пакетов проверены. У процесса окна отсутствовал слушающий HTTP-порт. |
| Ошибка зеркала | Контрольное зеркало вернуло HTTP 404 при загрузке `tree`. Pacman завершился с кодом 1, журнал сохранил ответ зеркала, `tree` отсутствовал в базе. |
| Запуск оболочки | В тестовом корне `serpantinumd start` запустил Quickshell поверх Plasma Wayland с программным рендерингом. Quickshell вывел `Configuration Loaded` и продолжил работу до остановки теста. Необязательные демоны, аппаратное ускорение и интеграция с Hyprland в этом запуске не проверялись. |
| Ограничения реального запуска | Вложенный Hyprland дошёл до разбора конфигурации и затем аварийно завершился при запуске EGL в VirtualBox без 3D. Физический Ventoy, вход в сессию через дисплейный менеджер и Fedora Live ISO в этот прогон не входили. |

Автоматические проверки охватывают PTY и пароль, подтверждение транзакции, неизвестное время загрузки, сетевую ошибку, блокировку pacman, недостаток места в Live, повтор, проверку RPM и развёртывание пользовательских файлов. Команды для повтора на Linux

```bash
python3 install/tests/installer_manager_test.py
python3 install/tests/native_packages_test.py

bash install/tests/install_runtime_test.sh
```
