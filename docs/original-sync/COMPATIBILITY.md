# Совместимость и атрибуция

- **CachyOS и Arch** используют штатный pacman. Umbriel берётся из настроенного репозитория либо из проверяемого пользователем рецепта umbriel-git с разрешением на AUR и сборку. Перед сборкой Umbriel отдельно проверяется рецепт обязательного портала, если он ещё отсутствует. Для полного обновления используйте установленную систему. [Документация Umbriel](https://docs.noctalia.dev/umbriel/installation/) · [PKGBUILD](https://aur.archlinux.org/cgit/aur.git/tree/PKGBUILD?h=umbriel-git)
- **Fedora** использует штатный DNF. Для Umbriel требуется доверенный Terra с umbriel-nightly. Ключи и подтверждения обрабатывает DNF. Развёртывание Hyprland и Quickshell испытано на Fedora 45 в отдельном корне с COPR. [Документация Umbriel](https://docs.noctalia.dev/umbriel/installation/)
- **Void** сохраняет XBPS и терминальный установщик. Для Umbriel используется сторонний репозиторий из оригинала с отдельным подтверждением подключения и штатным запросом доверия ключу. Нативное испытание нового пути остаётся открытым.
- **NixOS** сохраняет декларативные модули проекта. Для Umbriel оригинал рекомендует актуальный модуль самого композитора, поскольку более старый синтаксис не проходит проверку TOML. Сборка flake в этом прогоне не выполнялась. [Путь оригинала](https://github.com/ilyamiro/serpantinum/blob/2cce8546bdb1a72c0fd3bea86c82e6a75464f6c4/docs/configure/compositors/umbriel.md)
- **Профили обоев** привязаны к имени выхода и индексу активного пространства. Переименование выхода или перестановка динамических пространств требует проверить соответствие профиля. Системы без доступного определения активного пространства используют общий профиль. Режим совместимости GPU сохраняет прежний путь без шейдерных переходов.
