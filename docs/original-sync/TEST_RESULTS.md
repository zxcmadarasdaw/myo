# Результаты проверок

## Этап A. Установщик

| Среда | Результат |
| --- | --- |
| CachyOS Live в VirtualBox, отдельный корень | Нативный pacman установил Hyprland 0.57.2 и Quickshell 0.3.2. Подменённый внешний загрузчик не участвовал. После ответов HTTP 404 pacman переключился на настроенные зеркала. Версии подтвердились пакетной базой и запуском бинарников. Обнаружены hyprland.desktop и hyprland-uwsm.desktop. Ошибки отдельных хуков изолированного корня сохранились в отчёте. |
| Fedora 45, отдельный rootfs | Для Kitty 0.48.2-1.fc45 воспроизведён тот же краткий текст отказа в пустой базе RPM. Подробная проверка показала NOKEY при корректных дайджестах. После импорта ключа Fedora подписи и дайджесты прошли. Усечённая копия RPM отклонена. |
| Fedora 45, установка | Нативный DNF5 установил тот же пакет Kitty, Hyprland 0.56.2 из mineiro/hyprland и Quickshell 0.3.2 из errornointernet/quickshell. Штатный Quickshell 0.2.1 не удовлетворял минимуму проекта. Импорт ключа COPR прошёл через нативный запрос. Повторная установка Kitty использовала сохранённый RPM и загрузила 0 байт. |
| Linux, регрессии | Прошли 4 теста нативного запуска, 30 тестов очереди, 8 тестов менеджера установки, 8 тестов обновления ОС, 5 групп тестов подготовки и 30 проверок среды установки. |

Полное развёртывание на физическом SSD и полноценный Wayland-сеанс Fedora остаются открыты. Нативные испытания выполнялись в отдельных корнях внутри тестовой VM.

## Этап B. Интеграция

- Политика переходов прошла тест разных профилей двух выходов, наследования глобального профиля, скорости, размера ячейки и ключей Hyprland, Niri и Umbriel.
- В Qt прошли тесты Wallpaper Hub с локальными результатами, применения проверенного MP4, аудио обоев, восстановления настроек, Fusion, вариантов виджетов и Themess. Повторный набор Linux-регрессий установщика прошёл.
- QSB содержит SPIR-V, OpenGL/ES, HLSL и Metal. На Direct3D11 в Windows захвачено 160 тестовых кадров; для всех пяти эффектов изображения на 25% и 75% различались. В отдельном прогоне четырёх серий по 12 кадров частная память процесса составила 53,16, 53,37, 55,53 и 55,25 МиБ. Этот короткий прогон охватывает тестовую сцену Qt. Плавность живой анимации, память GPU и длительное переключение на физических мониторах Linux не измерены.
- Артефакт Core 0.8.0 прошёл SHA-256, запустился в Linux x86_64 и отдал sysinfo и два снимка watch history в изолированной D-Bus-сессии.
- TOML Umbriel разобран, все include найдены. Linux-тест проверил выбор источника пакета, обязательный AUR-портал и обнаружение записи Wayland. Полное создание сессии с AUR или Terra и интеграция рабочего стола остаются открыты.
- В тесте телеметрии сетевой вызов и запись идентификатора отсутствовали при настройке по умолчанию и при явном отказе.
- Микротест заметок выполнялся в Node.js на Windows. Один замер обрабатывал 180 отрывков из одинакового набора длинных заметок. Медиана семи прогонов — 115,95 мс у прежнего форматирования полного текста и 0,20 мс у ограниченного отрывка. Задержка отрисовки окна Qt отдельно не измерялась.
