# Результаты проверок

## Этап A. Установщик

| Среда | Результат |
| --- | --- |
| CachyOS Live в VirtualBox, отдельный корень | Нативный pacman установил Hyprland 0.57.2 и Quickshell 0.3.2. Подменённый внешний загрузчик не участвовал. После ответов HTTP 404 pacman переключился на настроенные зеркала. Версии подтвердились пакетной базой и запуском бинарников. Обнаружены hyprland.desktop и hyprland-uwsm.desktop. Ошибки отдельных хуков изолированного корня сохранились в отчёте. |
| Fedora 45, отдельный rootfs | Для Kitty 0.48.2-1.fc45 воспроизведён тот же краткий текст отказа в пустой базе RPM. Подробная проверка показала NOKEY при корректных дайджестах. После импорта ключа Fedora подписи и дайджесты прошли. Усечённая копия RPM отклонена. |
| Fedora 45, установка | Нативный DNF5 установил тот же пакет Kitty, Hyprland 0.56.2 из mineiro/hyprland и Quickshell 0.3.2 из errornointernet/quickshell. Штатный Quickshell 0.2.1 не удовлетворял минимуму проекта. Импорт ключа COPR прошёл через нативный запрос. Повторная установка Kitty использовала сохранённый RPM и загрузила 0 байт. |
| Linux, регрессии | Прошли 4 теста нативного запуска, 30 тестов очереди, 8 тестов менеджера установки, 8 тестов обновления ОС, 5 групп тестов подготовки и 30 проверок среды установки. |

Полное развёртывание на физическом SSD и полноценный Wayland-сеанс Fedora остаются открыты. Нативные испытания выполнялись в отдельных корнях внутри тестовой VM.
