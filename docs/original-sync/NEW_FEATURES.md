# Функции из оригинала

Исходный снимок — [2cce8546](https://github.com/ilyamiro/serpantinum/tree/2cce8546bdb1a72c0fd3bea86c82e6a75464f6c4), приложенный ZIP. При сверке ветки оригинала просмотрен также [220eb0f](https://github.com/ilyamiro/serpantinum/tree/220eb0f1dd27946a5b17b71f1763967ad9168837). Версии проверялись по исходникам, манифестам и артефактам.

| Возможность | Что перенесено и где | Что проверено |
| --- | --- | --- |
| Umbriel | Шаблоны TOML и автозапуск в [compositors/umbriel](../../compositors/umbriel). Выбор в графическом и терминальном менеджерах, провайдеры AUR, Terra и XBPS, проверка записи Wayland и TOML. В [UmbrielState](../../src/quickshell/singletons/system/UmbrielState.qml) подключён канал Core, в панели добавлены состояние и переключение рабочих пространств. | TOML и пути include, выбор рецепта, локальная проверка частей Core и синтаксиса. Полноценная сессия Umbriel ещё требует проверки. |
| Wave, Blinds, Clock, Hexagonal Grid и Ink Spread | Шейдер и QSB из оригинала в [transitions](../../src/assets/shaders/transitions). Предпросмотр, длительность и скорость в [настройках обоев](../../src/quickshell/guide/wallpaper), кнопка перехода к настройкам из Wallpaper Hub и применение через существующий движок. У Wave есть направление, у Blinds ориентация, у Clock и Ink начало. Hex имеет размер 20–240 и распространяется радиально, отдельного направления у оригинала нет. | Чтение QSB, отрисовка всех пяти шейдеров через Direct3D11, выбор эффектов и длительности, раздельные профили двух выходов, Qt-регрессии обоев. Замеры GPU на нескольких физических мониторах остаются открыты. |
| Профили переходов | [Wallpaper](../../src/quickshell/singletons/theme/Wallpaper.qml) хранит глобальный профиль и переопределения по выходу и активному пространству Hyprland, Niri или Umbriel. Кнопка возврата к общему профилю удаляет только локальное переопределение. Экспорт глобального профиля проходит через расширенную схему Themess. | Политика разделения выходов, глобальный запасной вариант, тесты Themess. |
| Core 0.8.0 | Зафиксированы версия и SHA-256 для [установщика](../../install/modules/core.sh), [Nix](../../nix/core.nix) и [AUR](../../packaging/aur). Совместимый уже установленный Core используется без запроса релиза. | Проверенный артефакт Linux x86_64 выполнил sysinfo и выдал выборки watch history. Сборки Nix/AUR не выполнялись. |
| Виджеты | Добавлен отдельный шрифт текста в [реестр](../../src/quickshell/widgets/WidgetRegistry.qml) и четыре текстовых варианта. Используется существующий механизм редактора и сохранения свойств. Desk Clock и System Monitor побайтово совпадали с ZIP, поэтому их пресеты сохранены. | Qt-регрессии вариантов, Fusion, загрузка виджетов в светлой и тёмной теме. |
| Заметки | Редактор создаётся при открытии заметки, а список форматирует короткий отрывок. [Notes](../../src/quickshell/quickactions/actions/Notes.qml) · [NotesFormat](../../src/quickshell/quickactions/actions/NotesFormat.js). | Проверки коротких и длинных заметок, замер подготовки отрывков в одинаковых условиях. |
| Приватность | Телеметрия при новой установке выключена. При отказе отсутствуют вызовы curl и генерация идентификатора. Убрано использование machine-id для запасного идентификатора. Подписанные ссылки зеркал очищаются в журнале пакетной транзакции. | Тест нового состояния и явного отказа с перехватом сетевой команды. |

Core 0.7.0 добавил канал IPC Umbriel, 0.8.0 добавил историю CPU, памяти и температуры. Действующие вызовы Core сохранены. Новая история оценена для системных виджетов, но их существующие независимые источники данных сохранены до отдельной проверки масштаба выборок и поведения при временной недоступности Core. [Изменения Core](https://github.com/ilyamiro/serpantinum-core/compare/v0.6.1...v0.8.0) · [релиз](https://github.com/ilyamiro/serpantinum-core/releases/tag/v0.8.0)

Сербский и хорватский действительно присутствуют в оригинале. В каждом каталоге совпали 1467 из 1898 английских ключей нашей версии. Эти каталоги пока не добавлены в выбор языков, чтобы 431 отсутствующая строка на язык не отображалась по-английски. Русский и английский имеют одинаковый набор ключей на проверенном снимке.

## Дополнительные кандидаты

- Сокращение ранней настройки команды msg из оригинала оценено отдельно. Здесь путь запуска зависит от состояния демона, восстановления и локализованных подсказок. Для переноса нужен замер тёплого и холодного вызова с сохранением этих сценариев.
- Локальная проверка совместимого Core перед обращением к GitHub перенесена. Она исключает запрос релиза при уже установленной подходящей версии и сохраняет проверку пакета при обновлении.
- Разбиение редактора виджетов оригинала рассмотрено. Наш редактор содержит Canvas и Fusion. Добавлено только отдельное свойство текста через действующий механизм, поскольку перенос целого редактора затронул бы сохранённые раскладки.
