# Serpantinum AI — дорожная карта

Целевая среда — Fedora 45, Hyprland и Quickshell на Qt 6. Основной вход — **Super + H → AI**. Первый работающий провайдер — локальный Ollama. Остальные провайдеры подключаются через общий интерфейс после проверки их API и условий использования.

Выполнять строго один этап за запуск. После каждого этапа сохранить изменения, запустить доступные тесты, обновить документацию, опубликовать отчёт и остановиться. Следующий этап начинается только после команды «Продолжай».

| Этап | Результат | Статус |
| --- | --- | --- |
| 1. Анализ и архитектура | Карта действующего кода, контракты компонентов, план проверки и инструкция для продолжения | Завершён |
| 2. Super + H → AI | Вкладка Connection, Models, Generation и Privacy в существующей панели. Состояние функций зависит от доступности backend | Завершён |
| 3. Backend | Реальная проверка связи, каталог и генерация через Ollama. Валидация, тайм-ауты, отмена, streaming и синхронизация с QML | Завершён. Проверен на HTTP-стенде |
| 4. Чат | Беседы, поиск, Markdown, подсветка кода, копирование, повтор, остановка и компактная панель | Завершён. Проверен в Qt и на HTTP-стенде |
| 5. Знание оболочки | Справка по реальным настройкам и командам, системная информация из действующих источников Serpantinum | Завершён. Проверен на стенде |
| 6. Действия | Типизированные операции, подтверждение, журнал, проверка результата и доступный откат | Завершён. Проверен на стенде |
| 7. Проверка | Регрессии AI и оболочки, оптимизация закрытой панели, итоговый отчёт и сценарий приёмки Fedora | Автоматические проверки выполнены. Живая приёмка Fedora открыта |
