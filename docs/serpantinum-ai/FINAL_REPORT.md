# Serpantinum AI — итог по семи этапам

Функции реализованы и прошли доступные проверки на Windows. Финальная приёмка на Fedora 45 с Hyprland, Quickshell и реальной моделью Ollama остаётся открытой.

| Этап | Результат |
| --- | --- |
| 1. Анализ | Определены вход в настройки, границы QML и backend, интерфейсы провайдера, истории и действий. |
| 2. Настройки | Вкладка Super + H → AI с параметрами подключения, модели, генерации и приватности. |
| 3. Backend | Локальный адаптер Ollama проверяет подключение, получает каталог и поддерживает поток, отмену и тайм-ауты. |
| 4. Чат | Компактная панель, несколько бесед, поиск, Markdown, копирование, повтор и опциональная SQLite-история. |
| 5. Данные оболочки | Справка о настройках и проверяемый снимок ОЗУ из Linux для соответствующих запросов. |
| 6. Действия | Фиксированные операции, подтверждение, локальный журнал и откат палитры и доступного рабочего пространства. |
| 7. Проверки | Регрессии, проверка широкой и компактной панелей, остановка работы делегатов при закрытии чата. |

## Использование

В работающей оболочке открыть `serpantinum settings ai`, проверить связь с локальным Ollama и выбрать установленную модель. Затем нажать «Открыть чат» или выполнить `serpantinum msg open ai`. Ключ для локального Ollama не требуется. Внешний провайдер CoArena в текущем выпуске отсутствует.

Опциональная история и журнал действий — отдельные SQLite-файлы в `${XDG_STATE_HOME:-$HOME/.local/state}/serpantinum/ai/`. Системные инструкции сохраняются отдельно в `${XDG_CONFIG_HOME:-$HOME/.config}/serpantinum/ai/instructions.txt`. Откат доступен в текущей сессии, пока состояние совпадает с результатом действия. Смена темы ограничена Dracula, Mocha, Nord и Tokyo. Переключение действует на существующие рабочие пространства текущего монитора Hyprland.

## Что подтверждено

Windows 11, Python 3.12, Qt/PySide 6.12, Node.js 24, Lua 5.4 и Git Bash. AI-бэкенд проверен через реальный дочерний Python-процесс и локальный HTTP-стенд. QML проверен с подставными сервисами Quickshell и отдельным Qt-окном. Перечень регрессий, пропусков и ошибок приведён в [TESTS.md](TESTS.md).

Видимая переписка получает поток пакетами. При закрытии окна поиск и делегаты сообщений отключаются. В Qt-стенде подтверждён пакет из 256 событий. Это функциональная проверка. Измерений FPS, CPU и RSS в Fedora не проводилось.

## Приёмка на Fedora 45

1. Проверить окружение и наличие локальной модели.

   ```bash
   hyprctl version
   hyprctl configerrors
   quickshell --version
   ollama list
   curl --fail http://127.0.0.1:11434/api/tags
   serpantinum settings ai
   ```

2. Войти через Super + H → AI. Проверить связь, выбор модели и сохранение настроек. Открыть чат, проверить поток, остановку, смену беседы, историю после перезапуска и ошибку при остановленном Ollama. Запустить его снова и повторить проверку связи.
3. Запросить использование ОЗУ, открыть Wallpaper Hub после подтверждения, сменить существующее пространство и тему, проверить журнал и откат. Сменить состояние перед подтверждением и убедиться, что старое предложение отклоняется.
4. Закрыть чат крестиком и Escape в разных рабочих пространствах. Проверить ввод на рабочем столе. Проверить Super + H/N/M, Super + Left/Right, Canvas, Themess, Wallpaper Hub, Widget Fusion, Music Studio, VPN, терминалы и Fastfetch в той же сессии.
5. Проверить приватные права файлов и сравнить CPU и RSS Quickshell до открытия чата, во время потока и после закрытия. Ollama измерять отдельно.

   ```bash
   stat -c '%a %n' "${XDG_STATE_HOME:-$HOME/.local/state}/serpantinum/ai/"*
   stat -c '%a %n' "${XDG_CONFIG_HOME:-$HOME/.config}/serpantinum/ai/instructions.txt"
   top -b -d 1 -n 10 -p "$(pgrep -n -x quickshell)"
   ```

Команды проверки прав предполагают, что история, журнал и инструкции были созданы. Ожидаемый режим файлов — `600`, каталогов AI — `700`.
