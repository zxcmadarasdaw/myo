# Wallpaper Hub

**Super+H** → **Поиск обоев**. Введите запрос на русском или английском, нажмите Enter или «Найти», затем выберите тип, минимальное разрешение и источник. «Авто» берёт разрешение самого большого монитора. «Все источники» объединяет совместимые включённые источники. Состояние и ошибки каждого источника видны в подробностях выдачи.

Последние запросы появляются под строкой поиска. В Sources можно отключить историю, удалить отдельную запись или очистить список. Сортировка «Наибольшее разрешение» упорядочивает записи каждой загруженной страницы. При сортировке «Новые» или «Популярные» источники без соответствующих метаданных объясняют пропуск.

## Галерея и просмотр

- Переключатель «Галерея» показывает до трёх крупных карточек. Если источник отдаёт короткий или уменьшенный ролик, он проигрывается без звука. Для него доступны пауза и повтор. На следующей странице плееры предыдущей выгружаются.
- Нажмите на карточку для большого просмотра. Стрелки интерфейса и клавиши Left / Right выбирают соседний результат. Для изображения 1:1 запрашивает оригинал, если он доступен. Из просмотра можно скачать, применить, открыть в Wallpaper Studio, добавить в избранное или присвоить имя коллекции.
- Колесо управляет масштабом изображения. В видео доступны перемотка и звук. «Проверить качество оригинала» измеряет один загруженный файл. Подпись Source Unknown означает, что у источника отсутствуют надёжные данные о происхождении файла.
- У результата со страницей есть «Открыть источник». Прямой файл имеет действие загрузки. После отклонения формата или отказа сервера карточка предлагает открыть страницу, если источник её указал.
- «Показывать результаты с неизвестным разрешением» включено по умолчанию. Такие результаты подписаны как неизвестные даже при фильтре 4K. Для строгого отбора отключите эту настройку в Sources.

## Источники

| Источник | Выдача | Доступ |
|---|---|---|
| Brave Search | Общий интернет-поиск картинок, анимаций и видео. Видеорезультат часто ведёт на страницу. | Пользовательский ключ и подходящий тариф. [Brave Images](https://api-dashboard.search.brave.com/api-reference/images/image_search), [Brave Videos](https://api-dashboard.search.brave.com/api-reference/videos/video_search/get) |
| Sepia Search | Публичные видео PeerTube. При большом просмотре Hub проверяет, разрешает ли платформа скачать одну из совместимых версий. | Без ключа. [PeerTube API](https://docs.joinpeertube.org/api-rest-reference/api/video.html) |
| Wallhaven и Openverse | Обои и индекс изображений, в том числе GIF в Openverse. | Без ключа. У Wallhaven есть необязательный ключ. |
| Wikimedia Commons | Изображения, GIF и видео. Если для видео есть уменьшенный MP4/WebM, он используется для просмотра. | Без ключа. Источник доступен при выключенном Safe Search. [TimedMediaHandler API](https://www.mediawiki.org/wiki/Extension%3ATimedMediaHandler/API) |
| Pexels и Pixabay | Фото и прямые MP4, включая 4K при наличии у поставщика. | Пользовательский ключ. |
| GIPHY | Предпросмотр GIF при отдельном выборе GIPHY в списке источников. Страница открывается в браузере. | Пользовательский ключ, отдельная выдача и атрибуция. [Условия API GIPHY](https://support.giphy.com/hc/en-us/articles/360028134111-GIPHY-API-Terms-of-Service), [ограничения интеграции](https://developers.giphy.com/docs/api/) |
| Steam Workshop | Страницы видеообоев Wallpaper Engine. Локальные файлы из установленной библиотеки можно подключить как папку. | Ключ Steam Web API и выключенный Safe Search для удалённого поиска. [Steamworks](https://partner.steamgames.com/doc/webapi/IPublishedFileService) |
| Мои обои | Личные файлы, скачанные записи и подключённые папки. Работает офлайн. | Пути выбираются в Sources. |
| Ссылки и ленты | Прямые ссылки на медиа, вложения RSS/Atom и JSON Feed. | После добавления ссылки источник включается. Для поиска в непроверенной ленте нужно выключить Safe Search. |

В Sources включайте нужные источники, сохраняйте ключи и запускайте «Проверить подключение». Ключи лежат в `~/.config/serpantinum/secrets/wallpaper_hub.json` с правами 600 на Fedora. `settings.json` хранит выбор источников и фильтры. История, списки папок и ссылок, избранное и коллекции находятся в каталоге `$QS_STATE_DIR/wallpaper_hub/`. Перевод запроса применяется к источникам с поиском на английском и показывается рядом с выдачей.

## Библиотека и применение

Перетащите JPG, PNG, GIF, WebP, APNG, MP4 или WebM в «Мои обои» или нажмите «Импорт файлов». Проверенные оригиналы сохраняются в `$WALLPAPER_DIR/Wallpaper Hub/`. Размер, формат, разрешение и параметры видеопотока измеряются после скачивания. Текущий файл в библиотеке заменяется только после проверки нового.

GIF и подтверждённые анимированные WebP идут в штатный слой анимаций. APNG остаётся в библиотеке в исходном виде. Для проигрывания он преобразуется в WebM через ffmpeg с VP9. «Установить» передаёт проверенный файл через `Wallpaper.setWallpaper`. Применение работает по выбранному монитору или по всем мониторам.

Возможность найти ролик конкретного разрешения зависит от выдачи провайдеров. Индекс стороннего сайта может содержать устаревшие или ограниченные ссылки. Исходник со страницы или закрытый поток открывается на сайте провайдера. Обычная миниатюра GIF не влияет на распознавание кадров оригинала.
