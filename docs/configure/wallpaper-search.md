# Поиск обоев (Search Wallpapers)

## Как открыть

**Super+H** → вкладка **Поиск обоев** (сразу после «Тема»). Раньше поиск был маленькой подвкладкой «Тема → Wallpaper Hub». Теперь это отдельная вкладка. Подвкладки «Приложения» и «VPN» в «Теме» остались на месте.

## Как пользоваться

1. Введите запрос на русском или английском и нажмите **Найти** (или Enter). Последние запросы появляются чипами под строкой. Историю можно отключить в настройках (⚙), очистить или удалить запрос по одному.
2. Фильтры: **Тип** (Все / Картинки / Анимация / Видео), **Мин. разрешение** (Авто = разрешение вашего самого большого монитора, Любое, 1080p, 1440p, 4K, 8K), **Сортировка** (По релевантности, Наибольшее разрешение, Новые, Популярные) и **Safe Search** (включён по умолчанию).
3. Под фильтрами показано состояние каждого источника: сколько он нашёл, сколько скрыто и почему, пропущен ли он (нет ключа, нет нужного типа, нет фильтра контента) или ответил ошибкой (лимит запросов, неверный ключ, нет сети). Остальные источники продолжают работать.
4. При наведении на карточку появляются кнопки **Просмотр**, **Скачать оригинал**, **Изменить** (Wallpaper Studio) и **Установить**. Прокрутка вниз подгружает следующую страницу; уже показанные карточки при этом не сдвигаются.
5. В просмотре есть «Вписать», 1:1 (загружает и показывает настоящий оригинал), масштаб колесом, проверка качества оригинала, а для GIF и видео — пауза, повтор, звук (по умолчанию выключен) и перемотка.
6. **Установить** скачивает оригинал, проверяет сигнатуру файла и его целостность (через ffprobe), сохраняет его в `$WALLPAPER_DIR/Wallpaper Hub/` и передаёт штатному Wallpaper Engine (`Wallpaper.setWallpaper`). Цель выбирается внизу: «Все мониторы» или конкретный монитор. Engine назначает обои по мониторам. Отдельных обоев для каждого рабочего стола у него нет.
7. **Скачанные** — уже загруженные и собственные обои. Список работает без интернета.

## Источники

| Источник | Что даёт | Ключ | Safe Search | Лимит |
|---|---|---|---|---|
| Wallhaven | JPG/PNG | не нужен (свой ключ необязателен) | свой фильтр (SFW; NSFW никогда не запрашивается) | 45 запросов/мин |
| Wikimedia Commons | JPG/PNG/GIF/WebM/OGV | не нужен | фильтра нет → используется только при выключенном Safe Search | fair use |
| Openverse | JPG/PNG/GIF | не нужен | свой фильтр `mature` | ≈100 запросов/день анонимно |
| Pexels | фото, MP4 до 4K | **ваш** бесплатный ключ | откровенный контент запрещён правилами сайта | 200/час, 20 000/мес |
| Pixabay | фото, MP4 | **ваш** бесплатный ключ | свой `safesearch` | 100/мин; без полного доступа к API фото отдаются максимум в 1280 px, и это помечается на карточке |
| Giphy | GIF | **ваш** ключ | рейтинг `pg` (при выключенном Safe Search — `r`) | 100/час для beta-ключа |

Ключи вводятся в настройках (⚙ → поле под источником → «Сохранить», ссылка «Получить» ведёт на страницу ключей источника). Они хранятся в `~/.config/serpantinum/secrets/wallpaper_hub.json` с правами 600. В `settings.json` и экспорт Themess они не попадают. Встроенных ключей нет. История поиска лежит в `$QS_STATE_DIR/wallpaper_hub/history.json` (до 25 записей).

## Честные ограничения

- Перевод: русский запрос переводится только для источников, которые не понимают русский (Wallhaven, Commons, Openverse, Giphy). Перевод показывается над результатами, и его можно отключить кнопкой «Искать без перевода» или в настройках. Pexels и Pixabay получают исходный запрос.
- Разрешение в карточке — то, что сообщил источник. После скачивания файл измеряется (ширина, высота, формат, размер, а для видео ещё кодек, FPS, битрейт и длительность), и карточка показывает уже измеренные значения. Высокое разрешение само по себе не доказывает оригинальность. Если происхождение неизвестно, показывается «Source Unknown».
- Сортировка «Наибольшее разрешение» упорядочивает каждую загруженную страницу. Источники, у которых нет дат или популярности, при «Новые»/«Популярные» пропускаются с объяснением.
- Анимированный WebP Wallpaper Engine показывает как статичную картинку. При установке об этом выводится предупреждение.
- Индекс Openverse бывает устаревшим: у некоторых файлов источник уже удалил оригинал. Такая карточка показывает «нет превью: файл мог быть удалён у источника».

## Проверка

```bash
python3 install/tests/wallhub_sources_test.py                 # офлайн: разбор Pexels/Pixabay/Giphy, кэш превью, список скачанных
.tools/qtvenv/bin/python install/tests/wallpaper_search_live_test.py --shots /tmp/shots   # настоящие запросы к API + настоящий QML
```

Живой тест использует настоящие API (нужен интернет) и реальный QML вкладки. Он проверяет запросы `anime girl white`, `аниме девушка в белом`, `Mr Robot`, `cyberpunk night`, все фильтры, Safe Search, просмотр 1:1, скачивание, установку, редактор, ошибку API, офлайн-режим, перезапуск и работу мыши после закрытия окон. Если источник сообщает о лимите запросов, тест ждёт минуту и повторяет.
