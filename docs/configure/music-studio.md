# Music Widget + Audio Studio

## Как открыть

В Widget Studio добавьте **Music**. Старые варианты **Full, Round, Lyrics, Simple Lyrics** сохранены. Новые: **Compact Glass, Minimal, Album Cover, Vinyl, Neon Music, Floating Player**.

Под настольным музыкальным виджетом находится полоска **Audio Studio**. Нажатие раскрывает панель; повторное нажатие, крестик или Escape закрывают её. При нехватке места снизу панель открывается вверх. На маленьком экране содержимое прокручивается. Геометрия сохранённого виджета не меняется; панель учитывает экранные координаты Infinite Canvas.

Первоначальная большая музыкальная панель тоже сохранена: **Super+M**, музыкальный блок панели либо `serpantinum msg toggle music`. Горячая клавиша действует при установленной соответствующей конфигурации композитора. **Super+H** не изменён.

В редакторе доступны прежние размер, позиция, поворот и прозрачность, а также полоска Audio Studio, анимации музыки, спектр и материал. Материалы: Liquid Glass, Mica, Neon Glass, Dark Minimal. Используются ThemeBackend, GlassFill, WallpaperBlur и штатный GPU Compatibility Manager. GlassFill зависит от выбранной общей темы и доступного backdrop; при отсутствии аппаратных эффектов остаётся читаемый тонированный фон. Отдельного материала Aurora Glass в проверенном коде не обнаружено.

## Что управляет звуком

MPRIS-контроллер остаётся общим для старых и новых музыкальных компонентов. **Auto** выбирает воспроизводящий плеер; ручной выбор закрепляет приложение, пока оно доступно. При его закрытии контроллер выбирает доступный плеер. Выбор сохраняется в `music.selectedPlayer` существующего Config. Приложения без Next, Previous, Seek или необходимой метаинформации получают отключённые соответствующие кнопки / обозначение неизвестной длительности.

Эквалайзер использует уже существующий **serpantinum-audio**, а не новый процессор и не EasyEffects. Python-адаптер передаёт прежнюю команду `serpantinum-audio ctl set` с десятью усилениями, балансом, mono, swap, dynamics, зарезервированным нулём и dynamic EQ. Он не устанавливает зависимости, не запускает движок и не перезапускает PipeWire. Штатное поведение запуска `serpantinumd` этим обновлением не изменено.

Полосы: **31 / 63 / 125 / 250 / 500 Hz / 1 / 2 / 4 / 8 / 16 kHz**, диапазон **−12…+12 dB**. Bass задаёт первые три полосы, Mid — полосы 4–7, Treble — 8–10. Это групповые регуляторы того же эквалайзера; отображаемое значение — среднее усиление группы. Изменения применяются при движении ползунка; отдельное Apply больше не требуется и закрытие панели не откатывает звук.

Volume/Mute управляют текущим `Audio.defaultSink` через существующий PipeWire singleton. Баланс работает через `serpantinum-audio`. Отключение **Эффекты** отправляет нейтральные параметры, сохраняя выбранную кривую для последующего включения; общий аудиодвижок не останавливается. **Dynamic EQ** сохраняет прежнее поведение: ручные полосы и тональные группы отключены, пока активен адаптивный режим. Mono, Swap, Dynamics и тест каналов по-прежнему доступны в первоначальной панели.

Пресеты имеют реальные параметры в `src/quickshell/media/equalizer.py`: сохранены Flat, Bass, Treble, Vocal, Pop, Rock, Jazz, Classic; добавлены Bass Boost, Electronic и Cinema. Изменение отдельной полосы отмечает профиль Custom. **Save Preset** сохраняет собственный именованный профиль; **Reset** обнуляет параметры обработки. Пресеты и настройки общие для всех экземпляров виджета.

При отсутствии движка, его узла PipeWire или необходимых инструментов панель показывает причину и блокирует эффекты. Процесс получает отдельные аргументы, без shell-интерполяции. Команды последовательны; частые движения одного регулятора объединяются. Успешный ответ UI появляется после нулевого кода возврата `ctl`. Это подтверждает доставку команды, но само по себе не доказывает изменение слышимого сигнала или маршрутизацию конкретного приложения.

## Сохранение и темы

Параметры расположения/оформления остаются в существующем WidgetSync и `wProps`.

Аудиоадаптер хранит подтверждённое состояние в `${XDG_STATE_HOME:-$HOME/.local/state}/serpantinum/music/studio.json`, именованные пресеты — рядом в `studio_presets.json`. Runtime-копия — `${XDG_RUNTIME_DIR:-/tmp}/serpantinum/music/eq_state.json`. Используются общий lock и атомарная замена файлов. При первой загрузке читается прежнее `serpantinum/audio.state`; неподтверждённые старые `pending`-настройки не выдаются за применённые. Сам движок, как и раньше, сохраняет собственное состояние. Загрузка UI только читает параметры и не меняет звук.

Themess получает новые варианты из WidgetRegistry. В `widgets.json` разрешены только четыре дополнительных поля оформления музыки:

```json
{
  "id": "music",
  "type": "music",
  "variant": "compactGlass",
  "x": 100,
  "y": 100,
  "w": 340,
  "h": 140,
  "musicDrawer": true,
  "musicMaterial": "liquid",
  "musicAnimations": true,
  "musicVisualizer": false
}
```

`preset`, `effects`, полосы EQ, команды, QML-обработчики и произвольные `wProps` из пакетов тем отклоняются валидатором. Импорт темы не применяет звук и не открывает панель автоматически.

Спектр опционален и использует существующие Spectrum/Visualizer и `serpantinum-audio visualizer`. Демо-данные отключены. Подписка снимается при закрытии панели; все прежние визуализаторы остаются на месте. Профиль GPU Performance отключает тяжёлые эффекты и движение обложки; частота спектра определяется существующей GPU-политикой.

## Проверка на Fedora 45 / Hyprland / Quickshell 0.3.2

Эта версия подготовлена на Windows. Следующие действия нужно выполнить на целевой системе; они не были выданы за пройденные тесты.

1. Перенесите **весь изменённый checkout**, включая новые файлы и `qmldir`. Не копируйте только MusicPopup.qml. Для проверки путей из корня checkout:

   ```bash
   command -v quickshell python3 serpantinum-audio pw-dump wpctl
   quickshell --version
   python3 install/modules/qml_check.py src/quickshell
   python3 src/quickshell/media/equalizer.py status
   wpctl status
   ```

   В JSON `status` проверьте `available` и `error`. Отсутствие аудиодвижка не мешает управлению плеером. Статус не запускает движок. Для эффектов нужен штатный `serpantinum-audio`, подключённый к текущему PipeWire; повторный независимый обработчик устанавливать не нужно.

2. Запустите обновлённую оболочку штатным способом. Для установленной тестовой копии в отдельной сессии без уже работающего Serpantinum:

   ```bash
   SERPANTINUM_DIR="$PWD/src" bash bin/serpantinumd start --verbose
   ```

   В обычной сессии сначала закончите текущий запуск оболочки привычным способом. Не запускайте две оболочки одновременно. `serpantinumd` сохраняет прежний запуск аудиодвижка и прежнюю миграцию EasyEffects; новое открытие Audio Studio таких действий не делает.

3. В Widget Studio добавьте Music / Compact Glass, затем проверьте все шесть новых и четыре старых варианта. Измените размер, прозрачность и материал. Переместите виджет к нижнему и правому краю; раскройте и закройте панель несколько раз, в том числе во время музыки. Проверьте прокрутку, Escape, ввод имени пресета, масштабирование мониторов и Infinite Canvas.

4. Запустите Spotify, браузер с MPRIS и локальный плеер. Проверьте Auto/ручной выбор, Play/Pause, Previous/Next, перемотку, обновление обложки, трек без обложки и неизвестную длительность. Закройте выбранный плеер, затем все плееры.

5. На умеренной громкости проверьте реальный звук: Flat → Bass Boost → Vocal → Rock → Electronic → Cinema; по отдельности Bass/Mid/Treble и полосы. Выключите Dynamic EQ для проверки ручных полос. Сравните Эффекты вкл/выкл. Убедитесь через `wpctl status` или имеющийся аудиопульт, что тестовое приложение действительно проходит через Serpantinum: приложения, обходящие его узел, эквалайзер не обрабатывает. Для измерительного подтверждения сравните спектр одного и того же тестового сигнала до/после; локальные mock-тесты этого не заменяют.

6. Проверьте Volume/Mute, крайние значения Balance, mono/swap/dynamics в старой панели, смену физического устройства и отключение устройства. Неподключённый движок должен дать сообщение и отключить эффекты, сохранив работу оболочки.

7. Сохраните собственный профиль, закройте/откройте панель, перезапустите оболочку и затем сеанс. Проверьте звук, профиль, выбранный плеер и геометрию виджета. Импортируйте тему только с параметрами оформления: звук не должен измениться.

8. Проверьте погоду, часы, старые визуализаторы, GIF/видео/Wallpaper Engine, Network Monitor, File Dock, Process Explorer, Terminal, Themess, Advanced Window Layouts, Infinite Canvas, материалы и Super+H. В журнале `${XDG_STATE_HOME:-$HOME/.local/state}/serpantinum/logs/shell.log` не должно быть новых `is not a type`, `ReferenceError`, `TypeError`, ошибок загрузки QML.

## Локальные автоматические проверки

```bash
python3 install/tests/music_effects_test.py
python3 install/tests/music_themess_test.py
python3 install/tests/music_qml_test.py  # нужен PySide6; служебные интерфейсы заменены тестовыми
node install/tests/music_drawer_test.cjs
python3 install/tests/qml_imports_test.py
```

Qt-изображения из теста находятся в `reports/music-studio/`. Они показывают настоящий код интерфейса с тестовыми плеерами, транспортом и заглушками материалов; это не скриншоты Fedora и не доказательство работы DSP.
