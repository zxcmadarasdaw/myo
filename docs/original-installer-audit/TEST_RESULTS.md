# Результаты проверки

Прогон от 18 ноября 2026 года. Оригинал — `57ab121b80358b4bd51bc0d49ecef40a6003d6db`. База изменений — `36461bb`. Для нативных проверок использовались отдельные тестовые корни внутри CachyOS Live 2026.08.09 в VirtualBox. Системная база пакетов Live и Windows в этих транзакциях не участвовали.

## Нативные транзакции

| Сценарий | Наблюдение |
| --- | --- |
| Pacman 7.1.0 / libalpm 16.0.1 | Fast установил 248 реальных пакетов. `pacman -Q` подтвердил Hyprland 0.57.2-1, Quickshell 0.3.2-1, `zfs-utils` 2.4.4-3 и `iana-etc`. Для core был указан отсутствующий локальный `CacheServer`, остальной набор скачался с настроенных HTTPS-источников. |
| Отчёт хуков | В минимальном корне отдельные хуки печатали `error: command failed to execute correctly` при нулевом коде pacman. Отчёт показал `SUCCESS_WITH_WARNINGS` и сохранил диагностическую строку. |
| Повтор после повреждения | В отдельном тестовом кэше испорчен `zfs-utils`. Для нового корня 16 архивов повторно использованы и один скачан заново. Проверка и установка 17 пакетов завершились успешно. |
| Проверка подписи | В отдельной временной копии подписанного `iana-etc` изменён байт после проверки checksum. Нативный pacman отклонил пакет с `invalid or corrupted package (PGP signature)`. Пакет отсутствовал в базе этого корня. |
| Hyprland и Quickshell | `pacman -Qk` подтвердил наличие 785 файлов Hyprland и 123 файлов Quickshell. Обе записи Wayland присутствуют. Вложенный Hyprland создал Wayland-сокет и ответил через `hyprctl`. Quickshell запустил минимальную панель и выдал `Configuration Loaded`. Устойчивое вложенное отображение проверку не прошло из-за ошибок EGL/GBM/DRM в госте, а соединение Wayland разорвалось. |
| Lua и сессия | При первой проверке в новом образе зафиксирован SIGSEGV в `Hyprland --verify-config`. Контрольная серия из 40 запусков проектной и 40 запусков минимальной конфигурации прошла. Тесты новой обвязки подтверждают восстановление после одного 139 и отказ после двух. `--session-check` показал локальную Plasma Wayland, дисплейный менеджер, TTY и отдельную SSH-сессию. |
| Fedora 45 / DNF5 | В отдельном Fedora rootfs нативно установлен подписанный `tree-2.3.1-2.fc45.x86_64`. Итоговый cache-only DNF сообщил `Need to download 0 B`. Изоляция Terra и сообщение о ненастроенном источнике проверены с заглушками. |

## Повторный замер скорости

Официальное зеркало Arch `geo.mirror.pkgbuild.com`, одинаковые 16 архивов, 242 010 807 байт (230,8 MiB), по одному проходу на холодном кэше. Измерено время загрузки с проверкой checksum. Повтор из тёплого кэша прошёл без обращений за архивами.

| Режим | Время | Средняя скорость | Максимум одновременно |
| --- | ---: | ---: | ---: |
| Stable | 36,97 с | 6,24 MiB/s | 1 |
| Balanced | 7,49 с | 30,82 MiB/s | 4 |
| Fast | 6,16 с | 37,44 MiB/s | 8 |
| Adaptive | 10,63 с | 21,71 MiB/s | 5 |

Adaptive снизил лимит при зависшем HTTP-ответе. Постепенное восстановление проверено отдельно тестом контроллера. Реальный прогон достиг пяти одновременных передач. В этом измерении Balanced оказался быстрее Adaptive. Поэтому Balanced остаётся режимом по умолчанию.

## Автоматические проверки

- Bash прошёл синтаксическую проверку 21 скрипта из GitHub checkout оригинала и изменённых локальных Bash-скриптов. Выполнены `py_compile` и `node --check`.
- `python3 install/tests/download_queue_test.py` — 34 теста. 651 позиция, 1/4/8 и Adaptive, реальный локальный HTTP timeout, зеркало после 404, сломанный и частичный архив, отсутствующая обязательная зависимость, повтор, cache-only и сообщения хуков.
- `python3 install/tests/installer_manager_test.py` — 6 тестов на Linux. Подтверждение плана, приватный журнал, PTY, сохранение плана и смена boot ID.
- `bash install/tests/installer_manager_test.sh` — 5 групп. Выбор компонентов, pacman lock, Live, backup и DNF. `bash install/tests/install_runtime_test.sh` — 30 проверок, включая восстановление Lua-валидатора, сохранение правок, нужные QML-типы, защиту дисплейного менеджера и Terra.
- Firefox в госте, визуальная fixture. Проверены Balanced по умолчанию, Retry Failed, две полосы прогресса, скрытие повтора при ошибке проверки и отображение сообщения нативного хука. Измерения сети сделаны отдельно реальными архивами.

## Границы приёмки

- Предыдущий прогон на том же типе Live VM подтвердил возврат к своей сессии при двух локальных сессиях Plasma Wayland и запрет активации чужой. Исходный отчёт о зависании в Hyprland не содержит системного журнала, поэтому причина не установлена. [Предыдущий протокол](../installer/TESTS.md)
- Полный запуск Serpantinum из дисплейного менеджера после установки на физическом CachyOS Live USB, повтор исходного зависания в Hyprland, полный upgrade системы, нативный DNF4, COPR/AUR, Void, NixOS и отдельные производные дистрибутивы не прошли нативную приёмку в этом прогоне. 651 позиция проверена автоматическим набором, а самая большая нативная транзакция содержала 248 пакетов.
