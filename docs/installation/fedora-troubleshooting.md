# Serpantinum на Fedora: проверка, обновление, диагностика

Документ описывает проверки, которые нужно выполнить **на реальной Fedora 45 + Hyprland**.
Исправления подготовлены и проверены на Windows (парсер QML, Qt offscreen, bash-тесты
с заглушками). Запуск в настоящей сессии Wayland/Hyprland там не выполнялся.

## 1. Обновление уже установленного Serpantinum

Установщик теперь при каждом запуске полностью копирует `bin/`, `src/` и `themess/`
в `~/.local/share/serpantinum`, в том числе незакоммиченные правки.

```bash
cd ~/путь/к/Serpantinum
bash install/install.sh
```

При обычном обновлении установщик сравнивает файлы Hyprland с версией предыдущего
коммита. Штатные `settings.lua` и `keybinds.lua` обновляются с резервной копией.
Если установщик сохранил вашу версию, сравните её с проектом и перенесите нужные
изменения вручную. Сначала сохраните копию:

```bash
cp -a ~/.config/hypr ~/.config/hypr_backup_$(date +%Y%m%d_%H%M%S)
```

Для режима окон перенесите обработчик `window.open` из `settings.lua` и замените
четыре существующие привязки окон соответствующими строками из `keybinds.lua`.
После обновления выполните
`hyprctl reload`, `hyprctl configerrors` и `serpantinum restart`.

Итог установки теперь честный: при отсутствии обязательных компонентов выводится
`was NOT installed completely` со списком ошибок, а код выхода равен 1.

## 2. Проверка окружения после установки

```bash
quickshell --version
```

```bash
Hyprland --version
```

Lua-конфигурацию (`hyprland.lua`) читает только Hyprland версии **0.55 и новее**. Более
старая версия запускается с автоматически созданным конфигом: без автозапуска, то есть
без оболочки и обоев. Установщик проверяет это и пытается обновить Hyprland из COPR.

```bash
rpm -q quickshell qt6-qtmultimedia qt6-qtwayland qt6-qtimageformats qt6-qtdeclarative kitty jq python3
```

`qt6-qtimageformats` обязателен: без него Qt не открывает обои в формате **WebP**,
а такие файлы есть в загружаемом наборе обоев.

Terra нужен **только для MangoWC** (пакет `mangowm`). Hyprland, Quickshell и
оболочка от него не зависят. Если Terra уже подключён в системе (`terra-release`
остался от прошлой установки MangoWC) и недоступен, dnf прерывал всю установку.
Теперь установщик отключает репозитории `terra*` (`--disablerepo`) во всех вызовах
DNF, кроме установки `mangowm`. Для MangoWC нужен заранее настроенный Terra с
доверенными ключами. Если репозиторий не настроен или недоступен, установка MangoWC
останавливается с сообщением о причине. Другие композиторы используют собственные
источники пакетов.

Проверить, подключён ли Terra:

```bash
rpm -q terra-release; ls /etc/yum.repos.d/ | grep -i terra
```

Если Mango больше не нужен, Terra можно удалить: `sudo dnf remove terra-release`.

## 3. Автоматические тесты

На Fedora (из корня репозитория):

```bash
bash install/tests/install_runtime_test.sh
```

На Linux этот тест также проверяет надзор `serpantinumd` (лог, 3 повтора, аварийный режим).

```bash
python3 install/tests/themess_test.py
```

```bash
python3 install/tests/gpu_compatibility_test.py
```

Тесты с Qt требуют PySide6 (`pip install --user PySide6`):

```bash
python3 install/tests/wallpaper_qml_test.py
```

```bash
python3 install/tests/themess_qml_test.py
```

```bash
python3 install/tests/apptheme_test.py
```

`apptheme_test.py` работает только на Linux (использует `fcntl`).

Проверка QML-типов по правилам Quickshell (без PySide6 выполняется только
статическая часть):

```bash
python3 install/modules/qml_check.py ~/.local/share/serpantinum/src/quickshell
```

```bash
python3 install/tests/qml_imports_test.py
```

### «X is not a type» и quickshell exit code 255

Quickshell загружает конфигурацию по адресам `qs:`, и Qt считает их удалёнными.
Поэтому соседние `.qml` в папке видны как типы, только если в папке есть `qmldir`.
Он может быть свой или созданный Quickshell, но Quickshell создаёт его лишь для
папок, до которых доходит через `import "папка"` от `Shell.qml`. Из-за этого
`wallpaper/WallpaperEngine.qml` (подключён через корневой `qmldir`) не видел
`WallpaperGif`, и вся оболочка не стартовала. Через `file://` (qmlscene, тесты
PySide6) тот же код загружается, поэтому раньше ошибку не замечали.
`install/modules/qml_check.py` повторяет правила Quickshell, а установщик
вызывает его в конце установки.

## 4. Ручная проверка в сессии Hyprland

1. Войти в сессию Hyprland. Должны появиться панель и обои.
2. `serpantinum logs` — в логе строка `starting quickshell ...` и нет повторных `exited with code`.
3. Super+W — выбрать JPG, PNG, WebP, GIF (GIF должен анимироваться) и WebM.
4. `serpantinum restart` — обои восстанавливаются.
5. Подключить второй монитор — на нём появляются те же обои, а не пустой фон.
6. Super+H → Themess — применить пакет MrRobot; обои меняются, «Восстановить» возвращает прежние.
7. Включить «Performance mode» — обои остаются, переходы и видео становятся статичными.

### Развёрнутый режим, Floating и Infinite Canvas

1. Откройте Firefox на обычном рабочем пространстве. Он должен заполнить рабочую область, оставив место зарезервированным панелям. Проверьте открытие диалога и штатный fullscreen через F11 или видеоплеер.
2. В `Super+H → Общие` найдите «Горячая клавиша плавающего окна». Введите `Ctrl + Z` и примените. При желании можно выбрать другую комбинацию. Пустое поле с применением отключает дополнительную комбинацию, `Super+Z` доступен сразу.
3. Нажмите `Ctrl+Z` в Firefox. При первом переходе окно занимает около 70% ширины и высоты доступной области. Проверьте, что оно принимает клавиатуру и мышь. Переместите и измените размер окна штатными сочетаниями из следующего раздела.
4. Перетащите Infinite Canvas на свободном участке рабочего стола и измените масштаб. Сравните координаты и размеры Firefox до и после. Холст меняет положение и масштаб виджетов, окно Firefox остаётся отдельной поверхностью Hyprland.
5. Переключитесь на другое рабочее пространство обычной привязкой или с панели и вернитесь. Firefox должен оставаться на своём пространстве. Повторите после переноса окна на другой монитор, если он подключён.
6. Повторный `Ctrl+Z` возвращает развёрнутый режим. Следующий возвращает сохранённую геометрию Floating. Проверьте выход из F11 в Floating, а также выключение дополнительной привязки и восстановление Undo в приложении.

Состояние геометрии относится к текущей сессии Hyprland и окну с тем же
идентификатором. Закрытие приложения завершает жизнь этого окна.

### Плавающее окно следует за курсором после отпускания кнопки

В Serpantinum `Super+Z` переключает режим окна и однократно задаёт размер и позицию.
Перетаскиванием управляет Hyprland. В Lua-конфигурации проекта `mouse:272` вызывает
`hl.dsp.window.drag()`, а `mouse:273` — `hl.dsp.window.resize()`. Обе привязки
используют `mouse = true`. Это штатный Lua-эквивалент `bindm` для Hyprland 0.57.1.

В активной сессии Fedora проверьте загруженную версию, ошибки и фактические привязки:

```bash
hyprctl version
hyprctl configerrors
hyprctl -j binds | jq '.[] | select((.key | test("mouse:(272|273)$")) or .keycode == 272 or .keycode == 273)'
hyprctl getoption binds:pass_mouse_when_bound
hyprctl getoption input:touchpad:drag_lock
```

С конфигурацией проекта ожидается по одной привязке на каждую кнопку с `modmask: 64`
(Super), пустым `submap`, `mouse: true`, `release: false` и `repeat: false`.
Ожидаемые значения двух настроек — `false` и `0` соответственно. Если привязки
отличаются, проверьте все загружаемые Lua-модули и локальные переопределения перед
перезагрузкой конфига командой `hyprctl reload`.

1. Откройте Firefox и нажмите `Super+Z`. Окно должно уменьшиться и оставаться на месте, пока двигается курсор без нажатой кнопки.
2. Переместите окно с `Super+ЛКМ`. Отпустите ЛКМ, продолжая удерживать Super, и сразу подвигайте курсор. Положение окна должно остаться прежним. Повторите с обратным порядком отпускания.
3. Измените размер через `Super+ПКМ`. Отпустите ПКМ и подвигайте курсор. Размер должен остаться прежним. Повторите перемещение за свободную часть заголовка без Super, если Firefox показывает заголовок.
4. Нажмите `Super+Z` дважды и убедитесь, что окно вернулось к предыдущему размеру и положению. Переключитесь между рабочими пространствами и вернитесь к окну.
5. Откройте Dolphin из лаунчера и терминал через `Super+Return`. Проверьте перемещение и отпускание кнопки на обоих окнах.
6. Откройте и закройте настройки через `Super+H`, затем редактор виджетов и Desktop Canvas. Повторите шаги 2–3. Проверьте, что `Super+N` открывает сеть и отображает VPN, а Wallpaper Engine и Themess доступны из оболочки.

Для проверки геометрии независимо от фокуса сначала узнайте адрес активного окна Firefox:

```bash
hyprctl -j activewindow | jq -r '.address'
```

Подставьте этот адрес вместо `0xАДРЕС` и запустите команду из терминала до проверки.
Сравните значения `at` и `size` после отпускания кнопки, продолжая двигать курсор.

```bash
watch -n 0.2 "hyprctl -j clients | jq -c '.[] | select(.address == \"0xАДРЕС\") | {floating, at, size}'"
```

Если окно продолжает двигаться, сравните физическую мышь и тачпад. Чтобы проверить,
поступает ли событие отпускания от устройства, найдите его в `sudo libinput list-devices`
и запустите `sudo libinput debug-events --device /dev/input/eventN`, подставив его номер.
Для физической мыши сопоставьте `BTN_LEFT`/`BTN_RIGHT` и `released` с изменениями геометрии.
Отдельно отметьте, воспроизводится ли зависание с `Super+ЛКМ`, за заголовок или только после
закрытия настроек. Эти результаты вместе с выводом `hyprctl` помогут локализовать причину.

В Hyprland 0.57.1 активное перетаскивание можно разово завершить из другого терминала
в той же сессии. Вызов вне обработчика нажатия попадает в ветку завершения операции.

```bash
hyprctl dispatch 'hl.dsp.window.drag()'
```

### Рабочие пространства и верхняя панель

Из распакованного каталога Serpantinum запустите `bash install/install.sh` и выберите «Обновить».
При обновлении из архива установщик сохраняет существующий `~/.config/hypr/config/keybinds.lua`.
Сравните его с `compositors/hyprland/config/keybinds.lua` из архива. Если в установленном
файле ещё нет `stepWorkspace`, перенесите эту функцию с её обёртками, новые привязки стрелок
и `Super+Alt+H/L`, заменив прежние привязки этих клавиш.

Затем выполните в текущей сессии Hyprland:

```bash
hyprctl reload
hyprctl configerrors
serpantinum restart
```

1. На пространстве №1 откройте Firefox, переведите его в обычный Floating через `Super+Z` и переместите в сторону.
2. Если с №1 направо ещё нет открытых пространств, нажмите `Super+Right`. Должно открыться №2, панель должна выделить №2, Firefox остаётся на №1.
3. Запустите терминал через `Super+Return`. Нажмите `Super+Left`. Панель должна выделить №1, а Firefox сохранить размер и положение. Кликните по №2 на панели и проверьте, что терминал остался там.
4. На чистом мониторе проверьте, что `Super+Left` с №1 и `Super+Right` с №8 не создают новых пространств за пределами ряда. С существующими пространствами внутри ряда стрелки выбирают ближайшее по направлению.
5. При двух мониторах включите раздельную нумерацию в настройках панели. Переключите пространство на одном мониторе и убедитесь, что второй сохраняет своё выделение. Измените число слотов, перезагрузите конфигурацию Hyprland и повторите проверку.

Сверить активные номера по мониторам можно командой `hyprctl -j monitors | jq '.[] | {name, activeWorkspace}'`.

### Infinite Canvas и окна Firefox

После установки проверьте, что в `~/.config/hypr/config/` есть `canvas.lua`.
Если вы используете свой `hyprland.lua` или обновляетесь из архива поверх
существующей конфигурации, добавьте `require("config/canvas")` в конец файла,
если этой строки ещё нет. Затем выполните `hyprctl reload`,
`hyprctl configerrors` и `serpantinum restart`.

1. На пространстве №1 откройте Firefox и нажмите **Super+Z**. Сдвиньте камеру вправо. Firefox должен уйти влево вместе с виджетами, а при большом сдвиге полностью исчезнуть.
2. Верните камеру. Убедитесь, что окно вернулось в исходное место, принимает клики и ввод с клавиатуры.
3. Переместите через **Super+ЛКМ** и измените размер через **Super+ПКМ**. После отпускания кнопки окно должно остановиться. Повторите сдвиг и возврат камеры.
4. Измените масштаб. Проверьте положение верхнего левого угла относительно виджетов и сохранение размера приложения.
5. Переключитесь на соседнее пространство через **Super+Right** и вернитесь через **Super+Left**. Сверьте номер на верхней панели и положение Firefox. Проверьте обычный и полноэкранный режимы, редактор виджетов, **Super+H** и **Super+N**.

Положение, размер и принадлежность окна можно снять до и после каждого шага.

```bash
hyprctl -j clients | jq '.[] | select(.initialClass | test("firefox"; "i")) | {at,size,workspace,floating,fullscreen,monitor}'
```

### VPN в Fedora и Fedora Live

Из каталога с обновлённым Serpantinum запустите `bash install/install.sh`.
Для восстановления только VPN из активной локальной сессии запустите
`bash install/install.sh --vpn-only`. Дождитесь `VPN components: READY`.
При ошибке причина появится в терминале и в
`~/.local/state/serpantinum/vpn/components-install.log`, а результаты проверки
будут в `components.json` в том же каталоге.

В **Super+N → VPN → Connection → sing-box** проверьте **VPN Engine Ready**.
Добавьте свою подписку, выберите сервер, проверьте подключение и отключение
сначала в Proxy, затем в TUN. Для Live без постоянного хранилища держите
Serpantinum и комплект `vpn-bundle/` на отдельном носителе и при необходимости
повторите установку после загрузки. Пакет RPM для офлайн-установки системных
зависимостей рассчитан на Fedora 45 x86_64.

## 5. Если обои не загружаются

```bash
serpantinum logs 200
```

Ищите строки `[wallpaper]`. Теперь при ошибке на экране показывается причина,
фон остаётся тёмным, а оболочка продолжает работать.

```bash
ls -la ~/.cache/serpantinum/wallpaper/
```

Файлы `current_<монитор>` содержат абсолютный путь к выбранным обоям. Проверьте, что файл существует и читается:

```bash
for f in ~/.cache/serpantinum/wallpaper/current_*; do case "$f" in *_name|*.png) continue;; esac; p="$(cat "$f")"; echo "$f -> $p"; ls -la "$p"; done
```

Типичные причины:

| Симптом | Причина | Решение |
|---|---|---|
| WebP не открывается | нет плагина Qt | `sudo dnf install qt6-qtimageformats` |
| MP4/MOV — ошибка видео | `ffmpeg-free` без H.264/HEVC | WebM (VP9/AV1) или `ffmpeg` из RPM Fusion |
| Папка обоев пуста | не скачался набор обоев | первый запуск берёт обои из `themess/*/wallpapers`; добавьте свои в `~/Pictures/Wallpapers` |
| Обоев нет совсем | старый Hyprland не прочитал `hyprland.lua` | см. раздел 2 |
| Нет обоев на новом мониторе | у монитора нет сохранённого файла | теперь берутся обои соседнего монитора |
| В логе `WallpaperGif.qml failed to load` | слой GIF не загрузился | остальные форматы работают; переустановите файлы (раздел 1) |
| `Your system does not have hyprland-guiutils installed` | у Fedora нет этого пакета, он есть только в COPR | Serpantinum он не нужен; для диалогов Hyprland: `sudo dnf copr enable mineiro/hyprland && sudo dnf install hyprland-guiutils` |

Сбросить выбор обоев:

```bash
rm -f ~/.cache/serpantinum/wallpaper/current_*
```

```bash
serpantinum restart
```

## 6. Если после входа пустой рабочий стол

Хоткеи, которые работают без оболочки:

- **Super+Return** — терминал (kitty);
- **Super+Ctrl+R** — перезапуск оболочки (`serpantinum restart`);
- **Super+Ctrl+Shift+Escape** — выход из сессии (если ваша версия Hyprland поддерживает `hl.dsp.exit`);
- **Super+M** — встроенный аварийный выход Hyprland, если в конфиге ошибка.

Если оболочка трижды подряд падает при запуске, `serpantinumd` показывает
уведомление и сам открывает терминал с концом лога.

```bash
serpantinum logs 200
```

```bash
serpantinumd status
```

```bash
command -v serpantinumd quickshell
```

```bash
hyprctl configerrors
```

Запуск оболочки вручную с выводом ошибок QML в терминал:

```bash
serpantinumd stop
```

```bash
quickshell -p ~/.local/share/serpantinum/src/quickshell/Shell.qml
```

Сообщения `module "..." is not installed` означают отсутствующий QML-модуль: обычно
`qt6-qtmultimedia`, `qt6-qtdeclarative` или устаревший `quickshell`.

## 7. Восстановление рабочего окружения

1. Переключитесь в TTY (Ctrl+Alt+F3) или войдите в другую сессию (установщик не трогает KDE Plasma).
2. Верните прежний конфиг Hyprland — резервные копии лежат в `~/.config/hypr_backup/`:

```bash
ls ~/.config/hypr_backup/
```

```bash
cp -a ~/.config/hypr_backup/backup_ДАТА/. ~/.config/hypr/
```

3. Повреждённые настройки: оболочка запускается с настройками по умолчанию и сохраняет
   копию испорченного файла как `~/.config/serpantinum/settings.json.corrupt`.
4. Откат Themess: Super+H → Themess → «Восстановить исходное».
5. Полная переустановка: `bash install/install.sh` и выбор переустановки.
