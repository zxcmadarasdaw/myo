# Архитектура

`GuidePopup.qml` → `WallpaperSearchTab.qml` → singleton `WallpaperSearch.qml` → Python `scripts/wallpaper/wallhub.py` → адаптеры поиска. Координатор параллельно опрашивает источники и передаёт QML события JSON Lines. Карточка и большой просмотр используют общий объект результата. Проверенный файл из библиотеки передаётся в `Wallpaper.setWallpaper`, который управляет действующим Wallpaper Engine.

Каталог обоев и базовый путь «Wallpaper Hub» остаются совместимыми с уже скачанными файлами. API-ключи хранятся отдельно от настроек и экспорта тем.

- Планировщик использует возможности источников, активные настройки и номер следующей страницы каждого источника. Сбой одного задания виден в его статусе. Кадры GIF/WebP/APNG подтверждаются по данным о кадрах или по ограниченному чтению оригинала.
- Запись результата содержит тип, известные размеры, страницы источника, ссылку для загрузки и отдельную ссылку предпросмотра при наличии. Страницы видео могут стать доступными для загрузки после подтверждения через PeerTube API. Качество для результатов без размеров оставляется неизвестным.
- Gallery ограничивает число активных плееров тремя. Cinema использует отдельный плеер и передаёт галерее выбранный индекс. Источник маленького клипа задаёт адаптер.
- Кандидат на импорт или загрузку проверяется во временном файле до помещения в библиотеку. Изменения индекса библиотеки записываются под блокировкой. APNG преобразуется в WebM по запросу, подтверждённый анимированный WebP использует текущий слой AnimatedImage.
