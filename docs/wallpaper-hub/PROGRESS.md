### Путь запроса и применения

| Узел | Текущая реализация |
|---|---|
| Search Coordinator | `WallpaperSearch.qml` хранит запрос, фильтры, результаты и активный процесс за пределами вкладки. `wallhub.py:cmd_search` планирует источники по `CAPS`, запускает их параллельно через `SOURCE_FUNCS` и публикует JSON Lines (`start → source → done`). QML игнорирует вывод отменённого процесса и прерывает поиск через 120 секунд. |
| Нормализация и фильтры | Адаптеры формируют общую запись через `item`. `ext_from` учитывает известный MIME и расширение. `classify_animations` проверяет кадры оригинала перед `guard`. QML применяет дополнительные фильтры качества и объединяет результаты по ID внутри страниц. |
| Video Search | Video — форма того же запроса с `--kind video`. Прямые ссылки Pexels/Pixabay зависят от ключей. Commons в режиме Video запрашивает `videoinfo`. Sepia возвращает страницы PeerTube и загружает метаданные отдельным процессом при открытии Cinema. |
| Animated Search | `--kind animated` маршрутизируется по возможностям каталога. Commons и Openverse просят GIF. Brave ищет GIF/WebP/APNG по типу файла. Локальные PNG и WebP анализируются по контейнеру. |
| Gallery Mode | `WallpaperSearchTab.qml → SearchCard.qml → GalleryVideo.qml`. Стрелки меняют набор до трёх карточек. Видеоплеер создаётся при наличии отдельной уменьшенной версии, GIF играет через `AnimatedImage`. Галерея не запускает оригинал видео автоматически. |
| Cinema / Preview Player | `SearchPreview.qml` использует Qt Multimedia и `AnimatedImage`, даёт навигацию, воспроизведение, паузу, звук, повтор и действия с результатом. Источники видео в порядке выбора — подготовленная локальная анимация, локальный файл, уменьшенный поток, оригинал по запросу. У внешней страницы есть переход к источнику. |
| Download Manager | `WallpaperSearch.qml:download` управляет одним процессом. `wallhub.py:cmd_download → save_media` проверяет Content-Type, лимит размера, сигнатуру и поток ffprobe во временном файле, затем переносит файл и обновляет запись My Wallpapers. |
| Wallpaper Engine | `applyPath` при необходимости вызывает `prepare-animation`, затем `Wallpaper.setWallpaper`. Штатный `WallpaperEngine.qml` управляет видео, переходами и звуком. GIF и подготовленный анимированный WebP используют `WallpaperGif.qml`, APNG может конвертироваться в WebM. |

### Почему пропадает видео

1. **План запроса.** При чистых ключах, Safe Search и Relevance у Video единственный сетевой адаптер — Sepia. Поиск по локальной папке участвует, когда выбран в UI. При выборе Newest или Popular Sepia исключается планировщиком и без ключей можно остаться без сетевого источника.
2. **Соединение.** На Windows Python `urllib` сообщает `certificate has expired` для Sepia и Commons. `curl.exe` к тем же публичным запросам вернул JSON при включённой проверке TLS. Этим подтверждена разница между клиентами в данной среде. Конкретная причина различий в цепочке доверия и результат на Fedora остаются неизвестными.
3. **Метаданные и пороги.** Первый ответ Sepia хранит длительность, но текущий маппинг оставляет размер, разрешение, формат и видео-URL пустыми. Все 24 разобранные записи `anime girl black` проходят 4K с включённым «Показывать неизвестные» как записи с неизвестным разрешением. При строгом 4K записей остаётся 0. То же для 1080p. Auto выбирает порог по экрану, а дополнительный QML-фильтр Known Quality независимо требует и размеры, и число байт. Ответ `resolve-peertube` применяется к карточке и Cinema, основной список повторно по размерам не фильтруется.
4. **Режим Commons.** С тем же запросом `city night timelapse` Video получил через диагностический транспорт 12 прямых WebM, у 11 есть отдельное превью. All использует `imageinfo`, поэтому не получил ни одного уменьшенного видеопревью и пропустил Ogg, для которого Video подобрал WebM-версию. Пустой `videoinfo` или отсутствие производной версии сейчас может дать запись `kind=video` без совместимого файла. [TimedMediaHandler API](https://www.mediawiki.org/wiki/Extension:TimedMediaHandler/API)
5. **MIME и расширения.** При неизвестном MIME или ответе типа `text/html` нормализатор поиска ещё может принять расширение URL за формат. `audio/webm` классифицируется как видео. Напротив, URL без известного расширения может остаться внешним даже при наличии файла. Проверка скачивания отдельно требует сигнатуру и реальный видеопоток. Подтверждение доступной версии и совместимости относится к конкретному файлу.

### Почему Animated неполон

- Remote GIF уже проверяется по оригиналу, поэтому статичная миниатюра сама по себе не превращает GIF в картинку. В живом Openverse 13 из 20 кандидатов подтвердились. Семь остались неподтверждёнными.
- Проверка читает максимум 1 МиБ с таймаутом 3 секунды. Длинный первый кадр, серверный отказ или повреждённые данные могут оставить GIF без подтверждения. Тогда запись маркируется как `image` с `animationUnconfirmed` и отсекается в Animated.
- Commons и Openverse в Animated запрашивают только GIF, поэтому animated WebP/APNG не попадают в эту ветку. PNG анализируется на APNG лишь в отдельных ветках Brave и Custom URLs при Animated. Для локального импорта проверка кадров выполняется отдельно.

### Пагинация и ошибки

- Sepia использует `start/count/total`, Wallhaven — `current_page/last_page`, Openverse — `page_count`. Commons вычисляет `gsroffset` вручную и использует наличие `continue` как флаг. Две реальные страницы прошли при `gsroffset=0/24`. Если API вернёт продолжение свойств, ручной offset может пропустить данные. [MediaWiki API Continue](https://www.mediawiki.org/wiki/API:Continue)
- QML увеличивает страницу отдельно у каждого успешного источника с `hasMore`. Если первая страница провайдера упала, курсора для «Ещё» у него нет до нового поиска. Следующая страница сохраняет курсор для повторения после ошибки. ID с префиксом источника подавляют повторы одного ID, межкаталожные дубликаты остаются. Resolution сортирует внутри страницы.
- HTTP 429 показывается отдельно, TLS выводится как ошибка источника. Повтор предусмотрен для транзиентных исключений, HTTP 504 в проверке BMW остался ошибкой Openverse, Wallhaven при этом вернул свою выдачу. `check-source` использует другой пробный запрос `nature`; для Commons это All и прямой вызов адаптера в обход планировщика. Успех пробы не гарантирует участие источника в Video с Safe Search.
