# Прогресс

## 1. Диагностика — COMPLETED

- Точка входа на ветке `wallpaper-search-2.0` с базовым коммитом `091a8de`: Super+H → «Поиск обоев». Super+M открывает музыку, Super+N — сеть, Super+Left / Right переключает пространства, Super+W открывает отдельный пикер. В рабочем дереве до начала уже были изменения Canvas, виджетов, тем, VPN, звука и движка.
- `WallpaperSearch.qml` запускает `wallhub.py`, принимает поток событий от выбранных адаптеров и обновляет плитки. Поиск без ключей с Safe Search не планирует ни одного видеозапроса: Commons исключён по фильтру контента, а Pexels/Pixabay требуют ключи. Giphy также требует ключ, Openverse ограничен своим индексом GIF.
- Дополнительные причины: неизвестное разрешение отбрасывается при любом пороге, Commons показывает статичный кадр до ручного запуска оригинала, WebP классифицируется как картинка без проверки анимации, а Openverse использует миниатюру для GIF. Частичная ошибка страницы может привести к пропуску страницы отдельного адаптера. Загрузка заменяет существующий файл перед проверкой ffprobe.
- В актуальной вкладке есть сетка, большой Overlay Preview, список скачанных и Wallpaper Studio. Отдельных Gallery/Cinema, коллекций и Steam-адаптера в этой версии не найдено. Пикер содержит собственный импорт. Текущий Engine применяет обои по мониторам, анимационный слой читает GIF, видеослой — MP4/WebM/MKV/MOV.
- Изменены только документы диагностики в этой папке. Живые запросы и сетевые ограничения зафиксированы в TESTS.md.
- Далее: добавить официальные широкие API в тот же координатор, различить файл и страницу и сохранить Safe Search.

## 5. Загрузка и библиотека — IMPLEMENTED, ENGINE CHECK PENDING

- Загрузка и импорт проверяют сигнатуру, MIME, видеодорожку и ожидаемый тип до публикации файла. Ошибка формата или HTTP 401/403/404/410 переключает карточку на действие «Открыть источник». Оригинал APNG сохраняется, WebM для просмотра и применения готовится через ffmpeg.
- Добавлены выбор и перетаскивание локальных файлов, избранное и именованные коллекции в избранном. Подтверждённый анимированный WebP использует тот же Qt-слой, что GIF. В `WallpaperEngine.qml` изменена проверка имени пути, существующие изменения Widget Fusion оставлены.
- Изменены backend, singleton, SearchCard/Preview/Tab, WallpaperGif и один предикат WallpaperEngine. Из 15 тестов backend два используют настоящие медиа ffmpeg: MP4 с отказом замены HTML и импорт/конвертация APNG.
- Далее: настройки и проверка подключения, локальные и пользовательские источники, сценарии QML и Wayland.
