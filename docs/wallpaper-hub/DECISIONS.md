# Решения

- Сохранить существующую вкладку, координатор, редактор и движок. Навигация по медиа использует обычные стрелки при активном просмотре. Глобальные бинды определяет Hyprland.
- Safe Search по умолчанию исключает удалённые источники без фильтра контента. Ошибки сертификатов обрабатываются с включённой проверкой TLS.
- Для широкого поиска выбраны официальные [Brave Images](https://api-dashboard.search.brave.com/api-reference/images/image_search) и [Brave Videos](https://api-dashboard.search.brave.com/api-reference/videos/video_search/get). Спецификация видео даёт ссылки и метаданные. Ссылка на страницу не используется как медиапоток.
- [Google Custom Search JSON API](https://developers.google.com/custom-search/v1/overview) закрыт для новых клиентов, старым нужно мигрировать к 1 января 2027. [Microsoft Bing Search APIs](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement) выведены из эксплуатации. [Sepia Search](https://sepiasearch.org/) работает без ключа и индексирует публичные PeerTube-видео.
- GIPHY доступен отдельно с официальным знаком, постером и анимацией в окне просмотра. Адаптер исключён из «Все источники», сохранения результатов и скачивания медиа. [Условия GIPHY](https://support.giphy.com/hc/en-us/articles/360028134111-GIPHY-API-Terms-of-Service), [руководство по API и официальный знак](https://developers.giphy.com/docs/api/)
- Выбранные папки и ленты хранятся локально в `sources.json`, избранное и имена коллекций — в `favorites.json`. В пользовательской ленте читаются только явные медиа-вложения. Steam Workshop показывает страницы видеообоев, локальная папка Steam подключается как обычная папка.
- Порог разрешения сравнивает обе стороны ориентации. Настройка неизвестного разрешения сохраняет полезные страницы и файлы без метаданных. Их подпись не заявляет 4K. Точную выдачу можно выбрать отключением этой настройки.
