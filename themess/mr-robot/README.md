# Mr. Robot для Serpantinum

Тёмно-синяя тема для Fedora с Hyprland и установленной сборкой Serpantinum с Infinite Canvas. Центральную часть экрана занимает зацикленная сцена из исходной GIF. Сверху слева расположены часы с датой и погода. Снизу находятся плеер, CPU, RAM и заметки. Свободный верхний правый угол оставлен для мини-карты. Верхняя панель содержит рабочие пространства, launcher, часы, трей и системные индикаторы.

## Импорт через Serpantinum

1. Откройте **Настройки → Общие → Пресеты**. Сохраните текущую конфигурацию кнопкой **Сохранить пресет**. При применении готового JSON Serpantinum заменяет текущий набор настроек оболочки настройками пресета.
2. Нажмите **Импорт**, выберите `Mr-Robot.json`, затем нажмите **Применить** на карточке **Mr. Robot**. Готовый файл содержит раскладку для выхода `eDP-1`. Если ваш экран называется иначе, замените ключ `eDP-1` в объекте `widgets` на имя своего выхода, например `DP-1`. Имя отображается в настройках экрана и в выводе `hyprctl monitors`.
3. Перетащите `wallpapers/mr-robot.webm` из файлового менеджера на свободное место рабочего стола нужного монитора. Штатный импорт удаляет поле с обоями из JSON, поэтому видео подключается отдельно. Для статичного фона перетащите `wallpapers/mr-robot-still.png`.

Если хотите собрать импортируемый JSON поверх своих текущих настроек, запустите команду из папки пакета в сессии Hyprland. Она читает настройки и выбирает монитор с фокусом. Для другого выхода перед перенаправлением добавьте `--monitor DP-1`.

```bash
python3 theme.py preset > Mr-Robot-local.json
```

В приложении выберите получившийся `Mr-Robot-local.json`. Если камера Canvas была сдвинута до импорта, вернитесь к началу координат через `serpantinum ipc call canvas home ""` или воспользуйтесь командой вписывания `fit`. Установщик ниже подгоняет начальный масштаб автоматически и включает видео в том же шаге.

## Установка из терминала

Извлеките папку `mr-robot` и откройте терминал **в запущенной сессии Hyprland**. Скрипту нужны Python 3, доступные в PATH `serpantinum` и `serpantinumd`, а для предпросмотра видео штатным движком обоев нужен `ffmpeg`. Выполняйте команды от своего пользователя.

```bash
cd /путь/к/mr-robot
python3 theme.py check
```

`check` покажет выбранный выход, логическое разрешение и пути установки. По умолчанию используется монитор с фокусом. Для конкретного выхода добавьте `--monitor DP-1` к `check` и `apply`. Список выходов показывает `hyprctl monitors`.

```bash
serpantinumd stop
python3 theme.py apply
nohup serpantinumd start >/dev/null 2>&1 &
```

Скрипт объединяет настройки темы с текущим `settings.json` и устанавливает раскладку, начальную камеру и фон на выбранном выходе. Цвета, панель, launcher и общие параметры Canvas действуют на всю оболочку. Док выключается, чтобы освободить нижний ряд для виджетов. Заметки берутся из текущего хранилища Serpantinum. Уже выбранные в Serpantinum интеграции оформления приложений могут подхватить новую палитру через штатный механизм оболочки.

Пакет подключается через сам Serpantinum. Если в Hyprland уже настроен запуск Serpantinum, он подхватит тему при следующем входе. Если автозапуска ещё нет, добавьте к своему существующему конфигу один вызов `serpantinumd start`. В Lua это `hl.exec_cmd("serpantinumd start")` внутри обработчика `hyprland.start`, в `hyprland.conf` это `exec-once = serpantinumd start`. Если в сессии уже запущены отдельная панель или менеджер обоев, проверьте их автозапуск при наложении слоёв.

## Проверка после запуска

```bash
# Пустая строка выбирает монитор с фокусом. Укажите имя, если выбран другой выход.
serpantinum ipc call canvas state ""
serpantinum info wallpaper DP-1  # Подставьте имя выбранного выхода.
```

На выбранном выходе состояние Canvas должно показывать `enabled: true` и `widgets: 6`. Перетаскивайте свободную область рабочего стола для панорамирования, прокручивайте колёсико для масштабирования. Мини-карта появляется при движении. Раскладка подгоняется при установке по логическому размеру монитора. На небольшом экране начальный масштаб может быть меньше 100%.

```bash
serpantinum ipc call canvas search ""  # Навигатор
serpantinum ipc call canvas fit ""     # Вписать все виджеты
serpantinum ipc call canvas home ""    # Начало координат и масштаб 100%
serpantinum msg toggle launcher
```

Для проверки погоды дождитесь штатного обновления данных и проверьте местоположение в Serpantinum. Чтобы проверить музыку, включите трек в MPRIS-плеере. Если видеодекодирование недоступно, установите тему с `--still` либо выберите включённый PNG через штатную команду, подставив имя своего выхода:

```bash
serpantinum set wallpaper "${XDG_DATA_HOME:-$HOME/.local/share}/serpantinum-themes/mr-robot/wallpapers/mr-robot-still.png" DP-1 fade
```

## Файлы

| В пакете | Назначение |
| --- | --- |
| `Mr-Robot.json` | Один готовый файл для штатного импорта в Serpantinum. |
| `palette.json` | Цвета, JetBrains Mono, радиус, прозрачность и штатный blur. |
| `panels.json` | Верхняя модульная панель, launcher, положение и состояние дока. |
| `widgets.json` | Пресет из шести штатных виджетов и их привязки к краям экрана. |
| `animations.json` | Плавная смена обоев за 600 мс. Анимации панели и виджетов выполняет Serpantinum. |
| `canvas.json` | Включение Infinite Canvas, скорость панорамирования, инерция, масштабирование и мини-карта. |
| `wallpapers/mr-robot.gif` | Исходная GIF. |
| `wallpapers/mr-robot.webm` | Основной бесшумный фон VP9, 1600×900. Исходная сцена помещена в центр на тёмной подложке. Видеоплеер Serpantinum повторяет ролик. |
| `wallpapers/mr-robot-still.png` | Статичный кадр для режима `--still` и предпросмотра. |
| `theme.py` | Создание персонального JSON, проверка путей, установка с резервной копией и откат. |

Штатный запуск в этой сборке использует следующие пути:

- `~/.config/serpantinum/settings.json` — фрагменты палитры, панели, анимаций и Canvas.
- `~/.local/state/serpantinum/widgets/<выход>/layout.json` и `canvas.json` — раскладка и камера выбранного выхода.
- `${XDG_DATA_HOME:-$HOME/.local/share}/serpantinum-themes/mr-robot/wallpapers/` — файлы фона.
- `~/.cache/serpantinum/wallpaper/` — текущий фон, имя и снимки для штатного движка.

Чтобы внести правки в пакет после применения, сначала выполните откат, затем отредактируйте соответствующий JSON и примените пакет повторно.

## Откат

```bash
serpantinumd stop
python3 theme.py restore
nohup serpantinumd start >/dev/null 2>&1 &
```

`restore` возвращает затронутые файлы к состоянию перед установкой. Если после применения темы вы редактировали `settings.json` или раскладку выбранного выхода, скопируйте их перед откатом, чтобы сохранить эти правки. Резервная копия находится в `~/.local/state/serpantinum/mr-robot-theme/active/`. После отката скрипт переименует её в `restored-…`.
